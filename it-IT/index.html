Editor di specifiche OpenAPI

La struttura segue la specifica reale, senza basarsi su ipotesi ricavate dall’indentazione. Esplora percorsi e componenti in un albero e correggi gli errori nel punto in cui si trovano.

  • Validazione basata sullo schema. Valida rispetto al dialetto 3.0, 3.1 o 3.2 effettivamente dichiarato nel file.
  • Navigazione dei riferimenti $ref. Vai alle definizioni, esamina gli utilizzi e ricevi suggerimenti per i riferimenti scritti in modo errato.
  • Modifiche direttamente nel file. Il tuo repository rimane la fonte autorevole.
  • Problemi associati alle regole. Gli errori della CI e la diagnostica dell’editor usano lo stesso linguaggio.

Debug delle API

Debug delle API rispetto alla specifica

Un’interfaccia per creare richieste familiare agli sviluppatori, con una capacità in più: verificare le risposte rispetto al contratto API.

  • Raccolte generate da percorsi e tag. Nessuna importazione e nessuna sincronizzazione manuale.
  • Verifica del contratto su ogni risposta. Individua direttamente proprietà non dichiarate, campi mancanti e tipi non conformi.
  • Ambienti e variabili. Riutilizza le configurazioni di sviluppo e staging esistenti.
  • Sicurezza da securitySchemes. La configurazione di Bearer, chiavi API e OAuth parte dalla specifica.

Generatore di server MCP

Genera un server MCP da OpenAPI

La tua specifica è già un manifesto di strumenti. Powerduck la compila in un server MCP eseguibile e mostra esattamente quali campi OpenAPI hanno generato ogni strumento.

  • Origine tracciabile. Ogni strumento è riconducibile alla sua operazione, al suo operationId e al suo schema.
  • Funzionalità ridotte e operazioni escluse sono visibili. I metadati mancanti vengono segnalati, anziché produrre silenziosamente strumenti poco affidabili.
  • Rigenerazione al salvataggio. Modifica la specifica: gli strumenti si aggiornano senza una fase di compilazione.
  • Trasporti locali. Esegui il server tramite stdio o HTTP per agenti e flussi di lavoro locali.

Generatore di documentazione API

Documentazione API dallo stesso contratto

Documentazione di riferimento generata direttamente dal modello OpenAPI, esportabile in file statici da ospitare dove preferisci.

  • Tabelle dei parametri dagli schemi. Campi obbligatori, enumerazioni e descrizioni rimangono sincronizzati.
  • Esempi in più linguaggi. Genera esempi cURL, Node, Python e Go dalle operazioni.
  • Risposte dal contratto reale. Le risposte di successo e di errore provengono dagli stessi oggetti validati dal debugger.
  • Esportazione statica. Nessuna dipendenza a runtime e nessun vincolo con una piattaforma di documentazione.

Domande frequenti

Le prime domande degli sviluppatori

Informazioni pratiche su file locali, versioni OpenAPI, generazione MCP e licenze.

Powerduck carica la mia specifica OpenAPI da qualche parte?

I file locali non richiedono un account. L’IA remota invia il contesto pertinente al fornitore configurato; la pubblicazione Cloud carica i contenuti selezionati solo quando lo decidi. Le statistiche d’uso facoltative sono disattivate per impostazione predefinita; consulta l’informativa sulla privacy per dati e controlli.

Quali versioni OpenAPI sono supportate?

OpenAPI 3.0, 3.1 e 3.2. Powerduck rileva la versione dichiarata e valida rispetto al dialetto appropriato, senza ridurre tutto al minimo comune denominatore.

Come viene generato il server MCP?

Le operazioni con operationId diventano strumenti MCP. Gli argomenti derivano dai parametri e dagli schemi requestBody. Gli schemi dei componenti possono essere esposti come risorse. Il server generato si aggiorna quando cambia la specifica.

La licenza desktop è un abbonamento?

No. Powerduck Desktop ha una licenza perpetua acquistata una sola volta. Include gli aggiornamenti della versione principale acquistata. Il passaggio a future versioni principali resta facoltativo.

Posso continuare a usare le raccolte Postman?

Sì. Puoi continuare a usare le raccolte e gli ambienti esistenti. Powerduck considera la specifica OpenAPI il contratto autorevole e aiuta a individuare le richieste che se ne discostano.

Funziona nella CI?

Sì. Lo stesso motore di validazione e generazione è disponibile tramite @powerduck/openapi-cli, uno strumento a riga di comando per pull request e pipeline automatizzate. Supporta test in batch su 6 protocolli (HTTP, SSE, WebSocket, gRPC, MCP, GraphQL), concorrenza configurabile e report compatibili con JUnit per l’integrazione nella CI.
