설치

Powerduck 데스크톱 클라이언트는 로컬 우선 앱입니다. 다른 데스크톱 프로그램처럼 설치되고 디스크의 실제 파일을 열며 계정 없이 사용을 시작할 수 있습니다.

다운로드​

Powerduck 웹사이트에서 플랫폼용 설치 프로그램을 받으세요. 다음 빌드가 electron-builder로 생성됩니다.

플랫폼설치 프로그램아키텍처
macOS.dmg(자동 업데이트용 .zip도)Apple Silicon(arm64)과 Intel(x64)
WindowsNSIS 설치 프로그램(.exe)x64
LinuxAppImage(.AppImage)x64

macOS​

  1. .dmg를 열고 Powerduck을 응용 프로그램으로 드래그합니다.
  2. 첫 실행 시 App Store 외부에서 다운로드한 앱을 여는 확인이 표시될 수 있습니다. 대화상자에서 허용하거나 앱을 우클릭해 열기를 선택하세요.
  3. Apple Silicon(M 시리즈)용 arm64 빌드와 Intel Mac용 x64 빌드 두 개가 게시됩니다. 머신에 맞는 것을 다운로드하세요.

Windows​

  1. NSIS 설치 프로그램(.exe)을 실행하고 설정 절차를 따릅니다.
  2. SmartScreen에 게시자가 인식되지 않는다고 표시되면 자세한 정보를 선택하고 실행하세요.

Linux​

  1. .AppImage를 다운로드합니다.
  2. 실행 권한을 부여하고 실행합니다.
chmod +x Powerduck-*.AppImage
./Powerduck-*.AppImage

AppImage는 시스템 전체 설치 없이 동작합니다. 일부 배포판에서는 마운트를 위해 FUSE 설치가 필요할 수 있습니다.

머신에서 동작하는 것​

데스크톱 클라이언트는 두 부분으로 구성된 Electron 앱입니다.

  • 파일 접근, 외부 HTTP 요청, 로컬 모크 서버, 데이터베이스 연결, 통합 터미널을 담당하는 메인 프로세스(Node.js).
  • 스펙, AI 채팅, 각 도구를 렌더링하는 렌더러(React 워크스페이스).

이 분리는 보안과 신뢰성에 중요합니다. 네트워크와 파일 시스템 접근이 필요한 요청을 WebView가 아닌 메인 프로세스가 처리해, 프롬프트와 API 키가 브라우저 콘솔에 나타나지 않고 브라우저에서 제공업체로의 직접 CORS 제한도 적용되지 않습니다. AI와 모델을 보세요.

시스템 요구 사항​

  • 현재 지원되는 macOS, Windows 10 이상, 또는 주요 Linux 데스크톱 배포판.
  • 앱을 둘 충분한 디스크 공간. 여는 스펙은 원래 위치에 남습니다.
  • 요청 전송, Git 소스 동기화, 호스팅 AI 모델 호출 시에만 네트워크가 필요하고 그 외에는 오프라인으로 동작합니다.

라이선스​

데스크톱 클라이언트는 자유롭게 평가할 수 있습니다. 구독 없이 한 번 구매하면 영구 라이선스로 판매됩니다. 라이선스 키는 구매 시 생성되고 한 번만 표시됩니다. 클라우드 호스팅은 구독형 별도 서비스입니다. 차이는 Cloud 청구를 보세요.

다음은 빠른 시작으로 진행하세요.
