청구

Powerduck에는 두 가지 다른 구매 모델이 있고 섞이지 않습니다.

데스크톱 클라이언트Powerduck Cloud
구매한 번 구매월간 구독
받는 것영구 라이선스 키호스팅 멤버십
만료만료 없음기간 종료 시 갱신

데스크톱 라이선스​

데스크톱 클라이언트는 한 번 구매 영구 라이선스로 판매됩니다.

  • 구매 시 라이선스 키가 생성되고 한 번만 표시됩니다.
  • 키는 SHA-256 해시로 저장돼 데이터베이스가 원본을 재구성할 수 없고 마지막 네 글자만 저장.
  • 상태: ISSUED, ACTIVE, SUSPENDED, REVOKED. 영구가 곧 철회 불가를 의미하지는 않습니다.
  • 키는 조직에 묶이고 활성화는 속도 제한됨.

이것은 Cloud 구독과 완전히 별개입니다. Cloud 구독을 사면 라이선스 키가 나오지 않습니다.

Cloud 구독​

Cloud는 월간 구독 호스팅 서비스입니다.

  • Pro——$19/월.
  • Team——$49/월.
  • Free——$0, 제한 있음.

구독은 기간이 있고 현재 기간 종료 시 갱신됩니다.

기능은 플랜 코드 비교가 아니라 권한으로 결정됩니다.

결제 제공업체​

지역에 따라 결제 경로가 선택됩니다.

  • 중국 본토, 홍콩, 동남아시아——Antom.
  • 유럽/미주, 일본, 한국——Paddle.
  • 지역 판단 실패 시 Antom으로 폴백.

두 제공업체는 동시에 쇼핑에 나타나지 않고, Paddle은 긴급 시 빠르게 전환할 수 있는 대비책입니다.

결제 흐름​

  1. 플랜 선택과 결제 시작.
  2. 결제 제공업체로 리다이렉트.
  3. 결제 완료 후 반환 페이지가 주문 상태를 확인.
  4. 웹훅이 결제를 확인하고 구독을 활성화.

주문은 멱등으로 처리돼 같은 결제가 두 번 적용되지 않습니다.

구독 수명 주기​

  • 업그레이드——즉시 적용. 남은 기간 가치를 기준으로 비례 차액 청구.
  • 다운그레이드——현재 기간 종료 시 적용(미리 알림).
  • 취소——현재 기간 종료 시 만료. 취소는 반복 확인을 거치며 대안 제시.
  • 만료——기간 종료 후 Free 한도로 되돌아감.

취소는 즉시 접근을 끊지 않고 현재 기간 끝까지 유지됩니다.

주문과 멤버십​

청구 페이지는 둘을 분리합니다.

  • 멤버십/구독——현재 플랜, 상태, 기간 종료, 갱신.
  • 주문——과거 구매와 결제 이력.

권한 확인​

모든 호스트 자원처럼 결제와 구독은 조직에 귀속되고 조직 스코프로 조회돼, 다른 조직 ID를 가진 사용자가 다른 팀의 주문을 읽을 수 없습니다.

관련: Cloud 소개、사용자 지정 도메인.
