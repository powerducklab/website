설정

데스크톱 클라이언트의 설정은 앱 외관과 요청 발송 방식을 다룹니다. 앱 수준 기본 설정은 API 문서 변경과 분리돼 테마 전환이나 프록시 구성이 계약을 바꾸지 않습니다.

외관​

  • 테마——라이트와 다크 전환(theme.get, theme.set). 변경이 앱 전체에 적용되고 영속화됩니다.
  • 인터페이스 언어——10개 언어 중 선택하거나 시스템 자동 추종.

요청 동작​

이 설정들은 요청 워크스페이스와 시나리오에서 나가는 외부 요청을 제어합니다.

  • 요청 시간 초과(requestTimeoutMs)——밀리초. 0은 무제한.
  • 엄격 SSL(strictSSL)——TLS 인증서 검증. 자체 서명이나 신뢰 안 된 인증서 서버에서 끌 수 있습니다.
  • 리다이렉트 추종(followRedirects)과 최대 리다이렉트(maxRedirects).
  • HTTP 버전(protocolVersion)——http1, http2, auto.
  • Cookie 비활성화(disableCookies)——요청 Cookie 처리를 끔.

프록시​

한 모드(off, system, custom)로 외부 프록시를 구성합니다.

  • off——프록시 미사용.
  • system——OS 프록시 추종.
  • custom——프록시 URL 사용, 선택적 사용자 이름, 암호, 우회 목록.

우회 목록은 호스트와 패턴을 받습니다(예: localhost,127.0.0.1, 와일드카드 호스트). 프록시 암호는 쓸 수 있지만 읽히지 않고 빈 값으로 지워집니다.

TLS와 클라이언트 인증서​

사용자 지정 신뢰나 양방향 TLS가 필요한 환경을 위해:

  • 사용자 지정 CA——CA 인증서를 켜고 경로를 제공하면 요청이 내부나 자체 서명 루트 인증서를 신뢰합니다.
  • 클라이언트 인증서(mTLS)——호스트별로 인증서 구성. 인증서/키 쌍 또는 PFX, 선택적 암호구. 호스트와 포트로 스코프 결정.

인증서는 추가, ID 지정 삭제, 또는 비울 수 있습니다. 인증서 암호구는 쓰기 전용으로 반환되지 않습니다.

통합 터미널​

앱에는 하단 터미널 패널이 있습니다.

  • terminal.open은 패널을 표시합니다. {"cwd":"document"}를 주면 현재 문서 폴더에서 열리고 호스트가 실제 절대 경로로 해석합니다.
  • terminal.run은 확인 카드 뒤 명시적 셸 명령을 입력해 실행합니다.

명령은 당신이 명시적으로 요청할 때만 실행되고 패널 표시로는 아무것도 실행되지 않습니다.

파일과 셸 동작​

  • shell.revealFile——현재 문서(또는 지정 경로)를 시스템 파일 관리자에 표시.
  • shell.openPath——기본 앱으로 파일 열기.
  • shell.openExternal——시스템 브라우저로 외부 제3자 페이지 열기.

Powerduck 공식 페이지는 전용 링크 도구(app.officialLink)를 써 앱을 떠나지 않고 대화 내 카드를 렌더링합니다.

클라이언트 코드 예제​

어떤 작업에든 어시스턴트가 바로 실행 가능한 클라이언트 코드를 생성하고(clientcode.generate) 언어와 클라이언트 라이브러리 전환이 있는 코드 카드로 보여줍니다. C, C#, Go, Java, JavaScript, Node, Kotlin, PHP, Python, Ruby, Rust, shell, Swift 등 지원. 코드는 대화에 붙지 않고 카드로 표시됩니다.

어시스턴트로 설정 변경​

테마/언어 전환, 프록시 설정, 인증서 오류 무시, HTTP 버전 변경 같은 앱 수준 요청은 API 설계 문제로 다뤄지지 않고 설정 도구로 처리됩니다. 설정 변경은 적용 전 확인을 요청합니다.
