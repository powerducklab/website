API 참조

@powerduck/openapi-request의 주요 통합 API 참조입니다. 표는 인터페이스 계약을 요약하며, 모든 오버로드와 선택적 매개변수는 패키지의 TypeScript 선언을 기준으로 합니다. 기본 진입점과 프로토콜별 하위 경로에서 내보내는 항목은 완전히 같지 않습니다.

핵심 API​

createClient(options?): ProtoClient​

UI 중심 클라이언트를 생성합니다. options 인수는 선택 사항입니다.

매개변수:

이름타입설명
optionsCreateClientOptions선택적 구성
options.writeBackWriteBackOptions응답을 명세에 병합하는 방식을 제어합니다
options.responseToResponseOptions응답 객체의 정규화 방식을 제어합니다

반환값: 다음 메서드를 제공하는 ProtoClient:

메서드시그니처설명
prepare(sendOptions: SendOptions) => PreparedRequest요청을 계획하고 프로토콜, 표시 모드, 스트림 종류를 반환합니다
send(sendOptions: SendOptions) => Promise<SendResult>요청을 실행합니다
sendMany(spec, targets, shared?) => Promise<SendManyResult>대상별 결과를 반환하며 일괄 실행합니다. 한 요청이 실패해도 다른 결과를 버리지 않습니다
connect(connectOptions: ManualSessionOptions) => AnyManualSession아직 열리지 않은 websocket/mcp/grpc 세션을 생성합니다. 연결하려면 open()을 호출하세요
discover(discoverOptions) => Promise<any>MCP와 gRPC 기능을 탐색합니다
writeback(spec, prepared, result, writeOptions?) => OpenApiDocument관찰된 응답을 문서에 병합합니다
dispose() => void현재는 아무 작업도 하지 않습니다. 호출자가 세션을 직접 닫아야 합니다
probeStreamingResponse(input: RequestInfo | URL, init?: RequestInit) => Promise<{ ok: boolean; status: number; contentType?: string; kind: "none" | "sse" | "ndjson" | "chunked"; response: Response }>fetch 요청을 실행하고 응답을 분류합니다. 반환된 응답 본문은 읽거나 취소해야 합니다

예제:

import { createClient } from "@powerduck/openapi-request";

const client = createClient({
  writeBack: { overwriteExamples: true },
});

const plan = client.prepare({
  spec,
  target: { operationId: "getUserById" },
});

const result = await client.send({
  spec,
  target: { operationId: "getUserById" },
  values: { path: { id: "42" } },
});

createDebugger(config?): ProtoKit​

자동화, 스크립트, CI를 위한 스크립트형 디버거를 생성합니다.

매개변수:

이름타입설명
configDebuggerOptions선택적 구성
config.adaptersProtocolAdapter[]기본 어댑터를 대체하는 사용자 정의 어댑터 목록
config.extraAdaptersProtocolAdapter[]기본 목록에 추가할 어댑터
config.writeBackWriteBackOptions명세 반영 옵션
config.responseToResponseOptions응답 정규화 옵션
config.writeBackTruncatedboolean잘린 스트림에서 추론한 스키마를 반영합니다(기본값: true)

반환값: prepare, send, sendMany, toCollection 등을 제공하는 ProtoKit.

예제:

import { createDebugger } from "@powerduck/openapi-request";

const dbg = createDebugger({
  writeBackTruncated: true,
});

const result = await dbg.send({
  spec,
  target: { operationId: "getUserById" },
  values: { path: { id: "42" } },
  serverUrl: "https://api.example.com",
});

createManualSession(options): AnyManualSession​

WebSocket, MCP, gRPC용으로 오래 유지되는 양방향 세션을 생성합니다. 팩터리는 I/O를 수행하지 않으며 open()을 호출할 때 연결합니다.

매개변수:

이름타입설명
options.kind"websocket" | "mcp" | "grpc"사용할 프로토콜
options.urlstringWebSocket 연결 URL
options.endpointstringMCP Streamable HTTP 엔드포인트
options.transport"streamable-http" | "stdio"MCP 전송 방식. 기본값은 Streamable HTTP입니다
options.command, options.argsstring, string[]MCP stdio용 로컬 실행 파일과 인수
options.address, options.service, options.methodstringgRPC 주소, 전체 서비스 이름, 메서드

gRPC에는 protoPaths 또는 reflection으로 설명자 소스도 제공해야 합니다. 프로토콜별 옵션은 구성을 참고하세요.

반환값: open(), send(), close(), onEvent(), waitForClose(), events, state를 제공하는 세션. onEvent()는 unsubscribe()를 가진 구독 객체를 반환합니다.

예제:

import { createManualSession } from "@powerduck/openapi-request";

const session = createManualSession({
  kind: "websocket",
  url: "wss://api.example.com/ws",
});

const subscription = session.onEvent((event) => {
  console.log(event.kind, event.data);
});
try {
  await session.open();
  await session.send({ type: "message", data: "hello" });
} finally {
  await session.close();
  subscription.unsubscribe();
}

AdapterRegistry​

ProtocolAdapter 인스턴스 레지스트리입니다. 새 레지스트리는 비어 있지만, createDebugger()는 사용자 정의 목록으로 대체하지 않는 한 내장 HTTP, WebSocket, gRPC, MCP, GraphQL 어댑터를 등록합니다. register(), unregister(), get(), list(), rank(), resolve()로 선택 과정을 관리합니다.

ProtoKitError​

디버거와 핵심 실행 경로에서 발생시키는 타입이 지정된 오류입니다. instanceof ProtoKitError로 라이브러리 오류와 예상치 못한 다른 실패를 구분하세요.

핵심 타입​

SendOptions​

prepare()와 send()의 기본 입력 객체입니다. 명세, 대상, 값과 요청 단위의 모든 구성을 전달합니다.

필드타입필수설명
specOpenApiDocument예완전한 OpenAPI 3.2 문서
targetOperationTarget예작업 식별자(아래 참조)
valuesRequestValues아니요경로/쿼리/헤더/쿠키/본문에 사용할 실제 값
serverUrlstring아니요spec.servers[0].url을 재정의합니다
serverVariablesRecord<string, string>아니요서버 URL 템플릿 변수
variablesRecord<string, string>아니요{{name}}으로 참조하는 환경 변수
globalsRecord<string, string>아니요Postman 방식의 전역 변수
localVariablesRecord<string, string>아니요로컬 변수
collectionVariablesRecord<string, string>아니요컬렉션 단위 변수
authAuthConfig아니요인증 구성
scriptsScriptConfig아니요요청 전 스크립트와 테스트 스크립트
runnerRuntimeRunOptions아니요postman-runtime 옵션 전체를 직접 전달합니다(최우선 적용)
websocketWebSocketOptions아니요WebSocket 전용 옵션
graphqlGraphQLOptions아니요GraphQL 전용 옵션
mcpMcpOptions아니요MCP 전용 옵션
grpcany아니요gRPC 전용 옵션
timeoutnumber아니요요청별 제한 시간(밀리초, runner.timeout.request의 편의 옵션)

SendOptions는 다음 실행 및 스트리밍 제어 옵션도 받습니다.

필드타입설명
fetchtypeof fetch지원되는 경우 호스트가 제공하는 격리된 fetch 전송을 사용합니다. HTTP/SSE는 계속 postman-runtime을 사용합니다.
writeBackbooleanfalse로 설정하면 responseFragment는 생성하지만 patchedSpec은 undefined로 유지합니다.
signalAbortSignal실행 또는 샘플링을 취소합니다. 부분 결과가 반환될 수도 있습니다.
maxEventsnumber유지할 스트리밍 이벤트의 최대 개수.
maxStreamMsnumber스트리밍 샘플링의 최대 시간(밀리초).
maxResponseSizenumber응답 크기 제한(바이트).
maxBufferCharsnumber이벤트 경계에 도달하기 전 SSE 파서의 버퍼 제한. 기본값은 4194304자입니다.
maxEventCharsnumberSSE 이벤트별로 유지할 데이터의 크기 제한. 기본값은 1048576자입니다.
inheritEventIdbooleanSSE 이벤트 ID가 없으면 마지막 ID를 이어받습니다. 기본값은 true입니다. 더 엄격하게 스키마를 추론하려면 false로 설정하세요.
onEvent(event: StreamEvent) => void스트리밍 이벤트를 수신합니다.
onConsole(log: ConsoleLog) => void스크립트 콘솔 출력을 수신합니다.
onAssertion(assertion: AssertionResult) => void어설션 결과를 수신합니다.
onResponseStart(info: ResponseStartInfo) => void초기 HTTP/SSE 헤더와 streaming 분류를 확인합니다.
onOpen(info) => voidWebSocket 연결의 URL, 프로토콜, 헤더를 수신합니다.

프로토콜 어댑터마다 제한값을 해석하는 방식이 다를 수 있습니다. UI 콜백은 가볍게 유지하세요. 콜백에서 발생한 예외는 실행 계층에서 처리합니다. HTTP 요청 설정에는 runner.requester를 사용하며, maxResponseSize를 지정한다면 0이 아닌 양수여야 합니다.

OperationTarget​

하나의 작업을 식별합니다. operationId 또는 method + path 중 한 방식을 사용하세요. 둘 다 지정하면 operationId가 우선합니다.

필드타입설명
operationIdstring대체 조회 키. 경로와 메서드보다 우선합니다
methodstring대소문자를 구분하지 않는 HTTP 메서드. path가 필요합니다.
pathstring/users/{id} 같은 템플릿 경로. method가 필요합니다.

RequestValues​

생성된 요청에 주입할 실제 값입니다.

필드타입설명
pathRecord<string, unknown>경로 매개변수 값
queryRecord<string, unknown>쿼리 매개변수 값
headerRecord<string, unknown>헤더 값
cookieRecord<string, unknown>쿠키 값
querystringstring미리 인코딩한 원시 쿼리 문자열(OpenAPI 3.2의 querystring 위치)
bodyunknown요청 본문
contentTypestring작업이 여러 요청 미디어 타입을 선언한 경우 특정 타입을 강제 지정합니다
const result = await client.send({
  spec,
  target: { operationId: "updateUser" },
  values: {
    path: { id: "42" },
    query: { version: "2" },
    header: { "X-Request-Id": "abc-123" },
    body: { name: "Alice", email: "alice@example.com" },
    contentType: "application/json",
  },
});

AuthConfig​

필드타입설명
typeAuthConfig["type"]인증 유형
tokenstringBearer 토큰(type: "bearer"용)
usernamestringBasic 인증 사용자 이름(type: "basic"용)
passwordstringBasic 인증 비밀번호(type: "basic"용)
keystringAPI 키 이름(type: "apikey"용)
valuestringAPI 키 값(type: "apikey"용)
in"header" | "query"API 키 위치(type: "apikey"용)
// Bearer token
const result1 = await client.send({
  spec,
  target: { operationId: "getUser" },
  auth: { type: "bearer", token: "your-jwt-token" },
});

// Basic auth
const result2 = await client.send({
  spec,
  target: { operationId: "getUser" },
  auth: { type: "basic", username: "admin", password: "secret" },
});

// API key in header
const result3 = await client.send({
  spec,
  target: { operationId: "getUser" },
  auth: { type: "apikey", key: "X-API-Key", value: "key-123", in: "header" },
});

고급 인증 유형에는 digest, oauth1, oauth2, jwt, hawk, aws4, ntlm, asap, edgegrid가 있습니다. HTTP/SSE/GraphQL용 Postman 인증 도우미 필드는 parameters: Record<string, string | boolean | number>로 전달합니다. 선택 사항인 oauth2: OAuth2FlowConfig는 OAuth 2.0 유형에서 토큰 획득과 갱신을 활성화합니다. 모든 인증 도우미가 모든 프로토콜에 적용된다고 가정하지 마세요.

PreparedRequest​

createClient().prepare()가 반환합니다. 디버거의 계획 결과는 다릅니다. createDebugger().prepare()는 located, adapter, plan을 포함하는 PlanResult를 반환합니다.

필드타입설명
protocolstring결정된 프로토콜(http, websocket, grpc, graphql, mcp)
transportstring결정된 전송 방식
targetOperationTarget원래 대상
operationany해석된 OpenAPI 작업 객체
display.modeDisplayMode"response" | "event-list" | "duplex-session"
stream.kindStreamKind스트리밍 분류(아래 참조)
stream.expectedboolean스트리밍이 예상되는지 여부
openapi.extensionsRecord<string, unknown>해석된 OpenAPI 확장
warningsstring[]계획 중 발생한 경고

StreamKind​

세부 스트리밍 분류: "none" | "sse" | "ndjson" | "chunked" | "websocket" | "graphql-stream" | "grpc-unary" | "grpc-server-stream" | "grpc-client-stream" | "grpc-bidi" | "mcp-http-stream" | "mcp-stdio"

OpenAPI 도우미​

내보내기 항목시그니처설명
locateOperation(spec, target) => LocatedOperationOperationTarget으로 작업을 찾습니다
inferSchema(value) => Schema단일 관찰값에서 JSON Schema를 추론합니다
inferSchemaFromMany(values) => Schema여러 관찰값을 포괄하는 스키마를 추론합니다
mergeSchema(a, b) => Schema추론된 두 스키마를 병합합니다(합집합 또는 조합)
sampleFromSchema(schema) => unknown스키마에 맞는 실제적인 예제 값을 생성합니다
toResponseObject(result, options?) => { statusCode: string; response: any }관찰 결과로 OpenAPI 응답 객체를 만듭니다
writeBackResponse(spec, path, method, fragment, options?) => spec관찰된 응답을 문서에 병합합니다

내보내는 타입: LocatedOperation, WriteBackOptions, ToResponseOptions.

HTTP / SSE​

다음 이름은 기본 진입점에서 사용할 수 있습니다. @powerduck/openapi-request/http 하위 경로는 HttpAdapter, SseParser, buildCollection, buildEnvironment, resolveServerUrl, buildRunOptions, runWithPostman을 내보냅니다. 탐지 도우미와 BUILTIN_CAPTURE_TEST는 기본 진입점에서 가져오세요.

내보내기 항목설명
HttpAdapterHTTP/HTTPS용 기본 프로토콜 어댑터
SseParserSSE 바이트 스트림을 구조화된 이벤트로 바꾸는 스트리밍 파서
isStreamingOperation선언된 콘텐츠 타입에 따라 작업의 스트리밍 여부를 분류합니다
isSseContentType콘텐츠 타입이 SSE를 나타내는지 확인합니다
isStreamingContentType콘텐츠 타입이 스트리밍을 나타내는지 확인합니다
acceptHeaderFor작업에 적합한 Accept 헤더를 생성합니다
probeStreamingResponsefetch 요청을 실행하고 응답을 분류합니다. 반환된 응답 본문은 읽거나 취소해야 합니다
BUILTIN_CAPTURE_TEST마지막 응답을 캡처하는 내장 Postman 테스트 스크립트

WebSocket​

@powerduck/openapi-request/ws에서 가져옵니다.

내보내기 항목설명
WebSocketAdapterWebSocket 대상용 프로토콜 어댑터
createWsManualSession양방향 WebSocket 수동 세션을 생성합니다. runWebSocketSession, wsManualSession이라는 별칭도 있습니다

GraphQL​

@powerduck/openapi-request/graphql에서 가져옵니다.

내보내기 항목설명
GraphQLAdapterGraphQL 대상용 프로토콜 어댑터
resolveGraphQLConfig작업에서 GraphQL 구성을 해석합니다
runGraphQLGraphQL 작업을 실행합니다

gRPC​

저수준 탐색, 호출, 설명자 도우미는 @powerduck/openapi-request/grpc에서 가져옵니다. GrpcProtocolAdapter, createGrpcManualSession, grpcManualSession, grpcDiscover, discoverGrpc는 기본 진입점에서 가져오세요. 하위 경로의 탐색 함수 이름은 discover입니다. 하위 경로에는 discoverFromCatalog, describeMethod, describeFromCatalog도 있어, 메서드마다 리플렉션을 반복하지 않고 카탈로그를 재사용할 수 있습니다.

오류 타입: ReflectionProtocolError, ReflectionUnavailableError, DescriptorDecodeError, GrpcDependencyBrokenError, GrpcDependencyMissingError.

추가 유틸리티​

기본 진입점은 OAuth 2.0 도우미 resolveOAuth2Token, acquireOAuth2Token, isOAuth2TokenExpired, oauth2RefreshStatuses, authFromOAuth2Token, 복제 유틸리티 toCloneable, 기본 클래스 UnifiedSession, gRPC 반영 도우미 writeGrpcOperations, discoverAndWriteGrpcOperations도 내보냅니다.
