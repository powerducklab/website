帳單與授權

Powerduck 出售兩種不同產品，對應兩種不同支付模式。把它們分開，是理解帳單最重要的一點。

桌面用戶端Powerduck Cloud
你買什麼桌面應用程式託管服務
模式一次性購買按月訂閱
有效期永久——永遠擁有當前計費週期
交付為授權碼，僅展示一次會員資格，無授權碼
可離線工作是否（它是託管服務）

Cloud 購買從不會產生授權碼，桌面購買也不是訂閱。

桌面永久授權​

桌面用戶端一次購買、永久擁有，沒有續費或計費週期。購買時產生授權碼：

  • 授權碼由加密安全的隨機位元組構成，格式為 PDC-XXXX-XXXX-…，而不是來自自增 ID 或時間戳；
  • 原始授權碼僅展示一次；
  • 資料庫只存授權碼的 SHA-256 雜湊和最後四個字元，因此無法從資料庫反推出原始授權碼。

授權狀態​

授權經歷四種狀態：

狀態含義
ISSUED已產生但尚未啟用
ACTIVE已啟用、可用
SUSPENDED暫時不可用；可重新啟用
REVOKED永久撤銷；不可重新啟用

「永久」意味著它不按計畫過期，並不意味著授權永遠不能被暫停或撤銷。

啟用與稽核​

啟用會校驗授權碼格式、對其雜湊、尋找雜湊、檢查狀態，並在交易中綁定授權。啟用端點有速率限制，以阻止暴力列舉。

每次授權碼狀態變化都記錄為一個授權事件——建立、啟用、暫停、重新啟用或撤銷——讓生命週期保持可稽核。

Cloud 訂閱​

Cloud 存取遵循對某計畫的有效訂閱，不涉及授權碼：

計畫按月按年計費
Free（免費）$0$0
Pro$19/月$15/月
Team$49/月$39/月

處於 ACTIVE 且在當前週期內的訂閱授予該計畫的能力。一個短暫的續費寬限期（三天）覆蓋續費前後的時間差；超出該視窗，存取解析為免費計畫。Cloud 能力從不會參考桌面授權。

計畫控制什麼​

計畫不是透過在程式碼庫中硬編碼計畫名稱來強制執行的。每個計畫有權益——布林功能和數值配額——透過統一的權益服務檢查：

支付服務商​

結帳按地區路由，讓客戶看到熟悉的服務商，兩個服務商從不同時出現：

  • Antom——中國大陸、香港、澳門、台灣和東南亞；
  • Paddle——美國、加拿大、歐洲、日本、韓國、澳大利亞、紐西蘭和英國。

國家根據用戶端時區或 Accept-Language 頭推斷；無需外部 GeoIP 資料庫。如果無法確定地區，以 Antom 兜底。在營運上也可以透過配置強制指定服務商，這樣在某一服務商出現故障時能立即切換到備用通道。

支付透過簽名的服務商 Webhook 確認（Paddle 和 Antom 各自獨立端點），而不是信任瀏覽器返回頁。

我該買哪個？​

  • 想要完整本機工作區、離線工作和永久擁有？一次購買桌面授權。
  • 想線上發布文件和 MCP 並分享穩定連結？訂閱 Cloud Pro（多席位選 Team）。
  • 很多團隊兩者都用：在用戶端本機設計和測試，然後在 Cloud 上託管已發布的 API。
