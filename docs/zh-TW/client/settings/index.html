設定

桌面用戶端的設定涵蓋應用程式的外觀和發起請求的方式。應用程式級偏好與對 API 文件的變更相互分開，因此切換主題或配置代理從不會改動合約。

外觀​

  • 主題——在淺色與深色之間切換（theme.get、theme.set）。變更套用於整個應用程式並被持久化。
  • 介面語言——選擇十種語言之一，或自動跟隨系統：

請求行為​

這些設定控制從請求工作區和場景發出的對外請求：

  • 請求逾時（requestTimeoutMs）——請求逾時（毫秒）；0 表示不限；
  • 嚴格 SSL（strictSSL）——校驗 TLS 憑證；對自簽名或不受信任憑證的伺服器可關閉它；
  • 跟隨重定向（followRedirects）和最大重定向次數（maxRedirects）；
  • HTTP 版本（protocolVersion）——http1、http2 或 auto；
  • 停用 Cookie（disableCookies）——關閉請求的 Cookie 處理。

代理​

用一種模式（off、system 或 custom）配置對外代理：

  • off——不使用代理；
  • system——跟隨作業系統的代理；
  • custom——使用一個代理 URL，可選使用者名稱、密碼和繞過清單。

繞過清單接受主機和模式（例如 localhost,127.0.0.1 和通配主機）。代理密碼可以寫入但從不會被讀回；寫入空值會清除它。

TLS 與用戶端憑證​

對於需要自訂信任或雙向 TLS 的環境：

  • 自訂 CA——啟用 CA 憑證並提供其路徑，讓請求信任內部或自簽名根憑證；
  • 用戶端憑證（mTLS）——按主機配置憑證，可以是憑證/金鑰對或 PFX 檔案，可選密碼短語；憑證按主機和連接埠確定作用域。

憑證可以新增、按 ID 刪除或清空。憑證密碼短語只寫、從不返回。

整合式終端機​

應用程式包含一個底部終端機面板：

  • terminal.open 顯示該面板；傳入 {"cwd":"document"} 可在當前文件所在資料夾打開，宿主會解析為真實絕對路徑；
  • terminal.run 在一張確認卡片之後，輸入並執行一條明確的 Shell 指令。

只有當你明確要求時才會執行指令；顯示面板不會執行任何內容。

檔案與 Shell 動作​

  • shell.revealFile——在系統檔案管理員中顯示當前文件（或給定路徑）；
  • shell.openPath——用預設應用程式打開文件；
  • shell.openExternal——在系統瀏覽器中打開外部第三方頁面。

Powerduck 官方頁面使用專門的連結工具（app.officialLink），它渲染一張對話內卡片，而不是離開應用程式。

用戶端程式碼範例​

對於任何操作，助手都可以產生可直接執行的用戶端程式碼（clientcode.generate），並在帶語言和用戶端程式庫切換器的程式碼卡片中展示。支援的語言包括 C、C#、Go、Java、JavaScript、Node、Kotlin、PHP、Python、Ruby、Rust、shell、Swift 等。程式碼在卡片中展示，而不是貼進對話。

透過助手變更設定​

應用程式級請求——切換主題或語言、設定代理、忽略憑證錯誤或變更 HTTP 版本——由設定工具處理，而不是被當作 API 設計問題。設定變更在套用前要求確認。
