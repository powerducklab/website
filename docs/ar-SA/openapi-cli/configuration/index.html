الإعدادات

تُحل الإعدادات وفق الأولوية: وسائط CLI > ملف الإعدادات > القيم الافتراضية. والنتيجة هي كائن CliConfig الذي تعيده resolveConfig.

CliConfig​

نوع الإعدادات الأساسي. جميع الحقول اختيارية باستثناء specPath.

الحقلالنوعالقيمة الافتراضيةالوصف
specPathstringمطلوبمسار أو عنوان http(s):// لمواصفات OpenAPI 3.2 بصيغة JSON
serverUrlstring(من المواصفات)تجاوز عنوان URL الأساسي للخادم في المواصفات
outputDirstring"./openapi-cli-report"مجلد كتابة ملفات التقارير
formatsReportFormat[]["json","cli","html"]صيغ التقارير المطلوب توليدها
filterFilterConfigundefinedتصفية العمليات المراد اختبارها
concurrencynumber5الحد الأقصى للطلبات المتزامنة؛ عدد صحيح من 1 إلى 100
timeoutnumber30000مهلة كل طلب بالمللي ثانية، عدد صحيح من 1 إلى 600000؛ تنطبق أيضًا عند جلب مواصفات بعيدة
proxystringundefinedعنوان وكيل HTTP(S)، مثل http://proxy:8080
tlsTlsConfigundefinedإعدادات TLS والشهادات
headersRecord<string, string>undefinedترويسات إضافية تُرسل مع كل طلب
authAuthConfigundefinedإعدادات المصادقة
variablesRecord<string, string>undefinedمتغيرات Postman بصيغة {{name}} المطلوب إدراجها
failOnErrorbooleantrueخاص بـ CLI: إرجاع رمز غير صفري بعد فشل اختبار؛ على مستخدمي المكتبة فحص التقرير
envFilestringundefinedمسار ملف .env يحتوي على زوج KEY=VALUE في كل سطر
grpcReflectionbooleanتلقائيgRPC: الأولوية للإعداد الصريح ثم امتداد العملية؛ وإلا يُفعّل عند عدم توفير مسارات proto
grpcProtoPathsstring[]undefinedgRPC: مسارات ملفات .proto أو مجلداتها
mcpTransport"streamable-http" | "stdio""streamable-http"MCP: وسيلة نقل عمليات MCP

mcpArgsstring[]undefinedMCP stdio: وسائط الأمر

ReportFormat هو النوع الاتحادي "json" | "cli" | "html".

خيارات التنفيذ المتقدمة​

الحقول التالية جزء من CliConfig أيضًا. يمكن توفير requester وmaxEvents وmaxStreamMs وmaxResponseSize في ملف JSON. بعد حل الإعدادات، مرّر signal وhttpRuntime وresolveTransport مباشرة إلى runTests() من الشيفرة؛ فهي كائنات وقت تشغيل وليست إعدادات JSON.

interface AdvancedRuntimeOptions {
  requester?: {
    followRedirects?: boolean;
    maxRedirects?: number;
    disableCookies?: boolean;
    protocolVersion?: "http1" | "http2" | "auto";
  };
  maxEvents?: number;
  maxStreamMs?: number;
  maxResponseSize?: number;
  signal?: AbortSignal;
  httpRuntime?: { certificates?: unknown; fileResolver?: unknown };
  resolveTransport?: (target: { protocol: string; url?: string }) => Promise<
    Pick<CliConfig, "proxy" | "tls" | "httpRuntime">
  >;
}

يتحكم requester في إعادة توجيه HTTP وملفات تعريف الارتباط واختيار البروتوكول. في HTTP/SSE، القيمة الافتراضية لـ maxEvents هي 50، ويستخدم maxStreamMs قيمة timeout إن لم يُضبط؛ ويُمرّر maxResponseSize إلى بيئة تنفيذ الطلبات. يستخدم gRPC قيمة maxStreamMs مهلةً للتدفق، ثم timeout، ثم 30000 مللي ثانية. يلغي signal التشغيل؛ ويوفر httpRuntime معالجة شهادات HTTP والملفات؛ ويحل resolveTransport إعدادات النقل لكل هدف.

DEFAULT_CONFIG​

كائن القيم الافتراضية المدمج الذي تصدّره المكتبة:

export const DEFAULT_CONFIG: Required<
  Pick<
    CliConfig,
    "outputDir" | "formats" | "concurrency" | "timeout" | "failOnError" | "grpcReflection" | "mcpTransport"
  >
> = {
  outputDir: "./openapi-cli-report",
  formats: ["json", "cli", "html"],
  concurrency: 5,
  timeout: 30000,
  failOnError: true,
  grpcReflection: true,
  mcpTransport: "streamable-http",
};

FilterConfig​

الحقلالنوعالوصف
methodsstring[]اختبار طرق HTTP هذه فقط، مثل ["get","post"]؛ استخدم أحرفًا صغيرة في الملفات، بينما يُطبّع إدخال CLI تلقائيًا
pathsstring[]اختبار المسارات المطابقة لأي تعبير نمطي؛ وإذا كان التعبير غير صالح تُستخدم مطابقة سلسلة فرعية
tagsstring[]اختبار العمليات التي تحمل أيًا من هذه الوسوم فقط
operationIdsstring[]اختبار قيم operationId المطابقة تمامًا فقط

إذا لم يتضمن المرشح أي مفاتيح، يُحل إلى undefined وتُشغّل جميع العمليات.

TlsConfig​

الحقلالنوعالوصف
caCertstringمسار حزمة شهادات CA بصيغة PEM
clientCertstringمسار شهادة العميل PEM لاستخدام mTLS
clientKeystringمسار المفتاح الخاص للعميل PEM لاستخدام mTLS
strictSSLbooleanتجاوز التحقق من شهادة TLS عندما تكون القيمة false؛ غير آمن
pfxstringمسار حزمة شهادات PFX؛ يتطلب gRPC صيغة PEM بدلًا منها
passphrasestringعبارة مرور مواد الشهادة المشفرة

ملاحظة: يقابل خيار CLI المسمى --insecure الإعداد tls.strictSSL = false، أي إنه يعطّل التحقق.

AuthConfig​

الحقلالنوعالوصف
typeAuthConfig["type"]آلية المصادقة؛ الأسماء المدعومة موضحة أدناه
parametersRecord<string, string | number | boolean>معاملات خاصة بالآلية تُمرّر إلى بيئة تنفيذ الطلبات
tokenstringرمز Bearer عند type: "bearer"
usernamestringاسم المستخدم عند type: "basic"
passwordstringكلمة المرور عند type: "basic"
keystringاسم مفتاح API عند type: "apikey"
valuestringقيمة مفتاح API عند type: "apikey"
in"header" | "query"موضع إدراج مفتاح API

قيم type المدعومة هي bearer وbasic وapikey وnone وdigest وoauth1 وoauth2 وjwt وhawk وaws4 وntlm وasap وedgegrid. يعتمد التوفر والمعاملات المطلوبة على البروتوكول وبيئة تنفيذ الطلبات؛ فتحديد الاسم وحده لا يضبط المصادقة.

حاليًا، لا ينتج خيار CLI المسمى --bearer إلا { type: "bearer", token }. ويمكن توفير إعدادات basic / apikey الأكثر تفصيلًا من ملف الإعدادات.

ملف إعدادات JSON​

الملف هو JSON عادي يتوافق مع Partial<CliConfig>. مرّره باستخدام --config <path> / -c. تكون الأولوية دائمًا لوسائط CLI على قيم الملف.

{
  "specPath": "./openapi.json",
  "serverUrl": "https://api.staging.example.com",
  "outputDir": "./reports",
  "formats": ["json", "html"],
  "concurrency": 10,
  "timeout": 15000,
  "failOnError": true,
  "proxy": "http://proxy.corp:8080",
  "tls": {
    "strictSSL": true,
    "caCert": "./ca-bundle.pem",
    "clientCert": "./client.crt",
    "clientKey": "./client.key"
  },
  "headers": {
    "X-API-Key": "${API_KEY}",
    "X-Environment": "staging"
  },
  "auth": {
    "type": "bearer",
    "token": "${BEARER_TOKEN}"
  },
  "variables": {
    "host": "api.staging.example.com"
  },
  "filter": {
    "methods": ["get", "post"],
    "tags": ["v2", "public"],
    "paths": ["^/api/v2"],
    "operationIds": ["getUser", "createUser"]
  },
  "grpcReflection": true,
  "grpcProtoPaths": ["./proto"],
  "mcpTransport": "streamable-http",
  "mcpCommand": "npx",
  "mcpArgs": ["-y", "@modelcontextprotocol/server-everything"],
  "mcpCwd": "./mcp-servers"
}

إذا لم يوجد الملف، يُطرح Config file not found: <path>؛ وإذا كان JSON غير صالح، يُطرح Invalid config file (must be JSON).

توسيع متغيرات البيئة​

بعد تحميل ملف .env عبر --env / envFile، تُوسّع مراجع ${VAR_NAME} في الحقول النصية التالية:

  • serverUrl
  • proxy
  • قيم headers
  • auth.token
  • قيم variables

مثال:

openapi-cli --spec openapi.json \
  --server 'https://${API_HOST}/v1' \
  --header 'Authorization: Bearer ${BEARER_TOKEN}'

سلوك .env: لا تُستبدل قيم process.env الموجودة؛ وتُزال علامات الاقتباس المفردة أو المزدوجة المحيطة بالقيم؛ وتُتجاهل الأسطر الفارغة وتعليقات #؛ ويُتجاوز الملف المفقود دون إشعار.

إنشاء الإعدادات برمجيًا​

import { resolveConfig, DEFAULT_CONFIG } from "@powerduck/openapi-cli";

const config = resolveConfig({
  spec: "./openapi.json",
  server: "https://api.staging.example.com",
  concurrency: 10,
  method: "get",
});

تطرح resolveConfig الخطأ "No OpenAPI spec path provided..." عند عدم توفير مواصفات، والخطأ Invalid proxy URL: <url> عندما لا تكون قيمة proxy عنوان URL صالحًا.
