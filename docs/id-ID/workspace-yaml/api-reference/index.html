Referensi API

Lapisan inti (@powerduck/workspace-yaml/core)​

FungsiDeskripsi
createWorkspaceYaml(options?)Menghasilkan string konten workspace.yaml
createOpenApiYaml(options)Menghasilkan string konten YAML OpenAPI 3.2
createWorkspaceWithApi(options)Menghasilkan konten ruang kerja dan OpenAPI sekaligus
parseWorkspaceYaml(content)Mengurai dan memvalidasi string workspace.yaml

createOpenApiYaml(options) — Opsi​

OpsiTipeWajibDeskripsi
titlestringYaJudul API
versionstringTidakNilai bawaan "1.0.0"
descriptionstringTidakDeskripsi API
contact{ name?, url?, email? }TidakInformasi kontak
license{ name, url? }TidakInformasi lisensi
serversArray<{ url, description? }>TidakDaftar server

Lapisan berkas (@powerduck/workspace-yaml)​

FungsiDeskripsi
initializeWorkspace(options)Membuat berkas workspace.yaml di disk
initializeOpenApi(options)Membuat berkas YAML OpenAPI di disk
createWorkspaceApi(options)Membuat kedua berkas secara atomik (rollback jika gagal)

createWorkspaceApi(options) — Opsi​

OpsiTipeWajibDeskripsi
workspaceDirectorystringYaDirektori tujuan
oasIdstringYaPengenal API unik
namestringYaNama tampilan
filestringTidakJalur relatif (bawaan: oasFiles/${oasId}.openapi.yaml)
titlestringTidakJudul API (bawaan: name)
versionstringTidakVersi API (bawaan: "1.0.0")
overwriteOpenApibooleanTidakNilai bawaan false

Kesalahan​

Semua kesalahan adalah instans WorkspaceYamlError dengan code yang dapat dibaca mesin:

KodeDeskripsi
INVALID_ARGUMENTParameter input tidak valid
ALREADY_EXISTSBerkas sudah ada dan penimpaan bernilai false
NOT_FOUNDBerkas tidak ditemukan
IO_ERROROperasi sistem berkas gagal
INVALID_WORKSPACEKonfigurasi ruang kerja tidak valid
INVALID_OPENAPIDokumen OpenAPI tidak valid
ROLLBACK_FAILEDRollback transaksi gagal
