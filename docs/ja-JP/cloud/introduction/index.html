Powerduck Cloud

Powerduck Cloud は OpenAPI ファイルを共有できるものに変えます。仕様を追加し、公開するものを選び、レンダリングドキュメントとマネージド MCP サーバーの安定リンクを他者に渡します。自分でホストしたり何かを実行したりする必要はありません。

それはデスクトップクライアントと同じ契約優先・AI 支援ワークフローを、チームと利用者のためにオンラインへ移したものです。

旅​

  1. 仕様を追加——ファイルアップロード、Git リポジトリ、URL のいずれか。ウェブサイトでフローを始め、準備ができたらログインすることもでき、二度アップロードする必要はありません。
  2. 公開するものを選ぶ。 操作を個別にオン/オフします。元ファイルは変更されません。
  3. ドキュメントリンクをすぐ開く——レンダリング API ドキュメントはデフォルトで有効。マネージド MCP エンドポイントは、エージェントにツールを公開すると選ぶまでオフのまま、スイッチ 1 つです。
  4. アクセスを制御する。 ドキュメント閲覧パスワードと有効期限、エージェント向けの独立した MCP アクセスキーを追加する。
  5. 公開して共有する。 現在バージョンの準備済み成果物を発行するとリンクが解決し、高度な制御はワンクリックで届きます。
  6. 最新を保つ。 変更ごとに新バージョンを作り、比較やロールバックができ、Git ソースは更新時に同期できる。
  7. ライフサイクルを管理する。 文書を一時停止、再開、アーカイブし、状態、バージョン、ソースを一目で確認する。

得られるもの​

  • 安定したドキュメントリンク——新バージョン公開後も読める。
  • マネージド MCP エンドポイント——他者の AI エージェントが選んだ操作を発見し呼べる。
  • 操作ごとの公開——内部や未完成のインターフェースを公開面から外せる。
  • アクセス制御——閲覧パスワード、有効期限、MCP アクセスキー。
  • バージョン履歴——比較とロールバック。元内容は決して上書きされない。
  • Git 同期——リポジトリ更新を新しいホスト版に流し込む。
  • カスタムドメイン——サブパス構成を含み、ブランド体験を提供。

1 文書、複数バージョン​

編集ごとに上書きではなく新バージョンを作るため、バージョン比較、ロールバック、特定状態に対するドキュメント/MCP の再公開ができます。ドキュメントと MCP は常に特定の文書とバージョンに紐づき、曖昧な「最新」を指すことはありません。

なぜリンクが開かないことがあるか​

3 つが揃ったときドキュメントや MCP リンクが解決し、文書ワークスペースは各項目を示し、最初の未達成要件を強調します。

  1. 文書がアクティブ状態——一時停止するとドキュメントと MCP が一緒に落ちる。
  2. 共有するモードが有効——ドキュメントと MCP にそれぞれスイッチ（ドキュメントはデフォルト有効、MCP はデフォルト無効）。
  3. 現在の成果物が公開済み——バージョン追加や公開操作変更後に自動構築されるため、通常操作不要。手動公開はフォールバックとして利用可能。

アクセスチェック——閲覧パスワード、有効期限、MCP アクセスキー——はこの 3 つの上で機能します。

ログインと帰属​

Google か GitHub でログインします。OAuth ハンドシェイク後、Powerduck は安全な HttpOnly Cookie で独自セッションを発行し、プロバイダーのトークンが長期身分として使われることはありません。すべては組織に帰属し、個人組織が自動作成されるため、後でチームが再設計なしに共有できます。

コンソール​

  • Dashboard——仕様を追加し、最近文書をクイックリンクと起動/停止操作付きで確認。
  • Projects——文書を整理。
  • 文書ワークスペース——状態、ドキュメント、MCP、公開操作、バージョン、ソース、ドメインを明確なタブで。
  • Billing——サブスクリプション状態と注文を分けて保持。
  • Hub——公開文書と MCP サーバーを公開し閲覧。
  • Settings と Activity——プロフィール、設定、監査ログ。

公開読者は専用ドキュメントビューアーを使い、文書がパスワードを求めない限りアカウント不要です。

Cloud とデスクトップクライアント​

デスクトップクライアントCloud
実行あなたのマシンホスト型
モデル買い切り永久ライセンス月額サブスクリプション
成果ライセンスキー（一度だけ表示）メンバーシップ、キーなし
適した場面ローカル、オフライン、完全ワークスペースオンライン共有と公開

両者は補完し合い、別々に販売されます。請求をご覧ください。
