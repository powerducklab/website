API リファレンス

@powerduck/conf-patch の全エクスポートについて、シグネチャと既定値をまとめたリファレンスです。

エントリーポイントは2つあります。

  • @powerduck/conf-patch — 以下のすべての機能。コア層、ファイル層、OpenAPI 検証、ユーティリティを含みます。
  • @powerduck/conf-patch/core — ブラウザー対応のサブセットのみ。patchContent、setContentValue、deleteContentValue、PatchContentOptions、アサーションヘルパー、ConfigFormat、JsonPatchOp、JsonPathSegment 型を含みます。

コア層（ブラウザー対応）​

patchContent​

設定文字列に RFC 6902 パッチ操作の配列を適用します。ファイルシステムにアクセスしない純粋関数です。

function patchContent(
  content: string,
  ops: JsonPatchOp[],
  format: ConfigFormat,
  options?: PatchContentOptions,
): string;
パラメーター型説明
contentstring元の設定内容。指定した format として有効である必要があります。
opsJsonPatchOp[]順番に適用する操作。空の配列では content を変更せず返します。
formatConfigFormat"json" | "jsonc" | "yaml"。
options.strictbooleantrue（既定値）では操作の失敗時に例外を送出します。false ではスキップし、console.warn で警告します。

戻り値: パッチ適用後の設定内容（string）。

例外: content が文字列でない場合や ops が無効な場合は TypeError。strict が true の場合は失敗した操作を示すエラー。

import { patchContent } from "@powerduck/conf-patch/core";

patchContent(
  '{"name": "app"}',
  [{ op: "add", path: ["version"], value: "1.0.0" }],
  "json",
);
// => '{\n  "name": "app",\n  "version": "1.0.0"\n}'

setContentValue​

単一の値を設定または作成します。内部で patchContent に1つの add 操作を渡します。RFC 6902 に従い、add は既存のオブジェクトプロパティを置換するか、配列の指定位置に挿入します。

function setContentValue(
  content: string,
  path: readonly (string | number)[],
  value: unknown,
  format: ConfigFormat,
): string;
パラメーター型説明
contentstring元の設定内容。
pathreadonly (string | number)[]["server", "port"] などの区切られたパス。空にはできません。
valueunknown書き込む値。
formatConfigFormat設定形式。

戻り値: 更新後の内容（string）。

setContentValue("server:\n  port: 3000\n", ["server", "port"], 8080, "yaml");

deleteContentValue​

キーまたは配列要素を削除します。内部で patchContent に1つの remove 操作を渡します。対象パスが存在する必要があります。

function deleteContentValue(
  content: string,
  path: readonly (string | number)[],
  format: ConfigFormat,
): string;
deleteContentValue(
  '{"name": "app", "legacy": true}',
  ["legacy"],
  "json",
);

PatchContentOptions​

interface PatchContentOptions {
  /** When true, failed operations throw. When false, they are skipped with a warning. Default: true */
  strict?: boolean;
}

ファイル層（Node.js / Electron のみ）​

readConfigFile​

ローカルパスまたは file:// URL から UTF-8 テキストを読み込みます。

function readConfigFile(filePath: string): Promise<string>;
パラメーター型説明
filePathstring絶対パス、相対パス、または file:// URL。空にはできません。

戻り値: 元の UTF-8 内容（Promise<string>）。

例外: 読み込めない場合、元のファイルシステムエラーを含むエラー。

writeConfigFile​

一時ファイルと名前変更によるアトミック書き込みを行います。既定では排他的なファイルロックを使用します。ロック前に親ディレクトリを作成します。

function writeConfigFile(
  filePath: string,
  content: string,
  options?: WriteConfigOptions,
): Promise<void>;
パラメーター型説明
filePathstring設定ファイルへのパス。
contentstring書き込む内容。文字列である必要があります。
optionsWriteConfigOptions下記を参照。

例外: 無効な入力では TypeError。書き込み時のファイルシステムエラーはラップされます。

WriteConfigOptions​

オプション型既定値説明
lockbooleantrue書き込み中のファイルロックを有効にします。
lockTimeoutMsnumberwithFileLock の既定値（10 秒）ロック取得まで待機する最大時間（ミリ秒）。
lockRetryDelayMsnumberwithFileLock の既定値（25 ミリ秒）指数バックオフ前の初回再試行待機時間（ミリ秒）。
lockStaleThresholdMsnumberwithFileLock の既定値回復が許可されるまでのロック経過時間（ミリ秒）。
allowStaleRecoverybooleanfalse古いロックの自動回収を許可するかどうか。
import { writeConfigFile } from "@powerduck/conf-patch";

await writeConfigFile("config.json", '{"name": "app"}');

patchConfigFile​

ファイル層の主要なトランザクションです。ロック内で読み込み、patchContent を適用し、内容が変わった場合のみアトミックに書き戻します。options.format を省略すると拡張子から形式を判定します。

function patchConfigFile(
  filePath: string,
  ops: JsonPatchOp[],
  options?: PatchConfigOptions,
): Promise<void>;
パラメーター型説明
filePathstring設定ファイルへのパス。空にはできません。
opsJsonPatchOp[]適用する操作。空の配列では読み書きせずに戻ります。
optionsPatchConfigOptions下記を参照。

例外: filePath が空、ロックオプションが無効、または形式を判定できず format も指定されていない場合は TypeError。strict が true の場合は操作エラー。

PatchConfigOptions​

オプション型既定値説明
formatConfigFormat自動判定明示的な形式。拡張子による判定より優先します。
strictbooleantrue操作の失敗時に例外を送出します。
lockbooleantrueファイルロックを有効にします。
lockTimeoutMsnumber10 秒0 以上。ロックの最大待機時間。
lockRetryDelayMsnumber25 ミリ秒正の値。初回再試行待機時間。
lockStaleThresholdMsnumber計算値正の値。古いロックの回復に必要な経過時間。
allowStaleRecoverybooleanfalse古いロックを自動回収します。
await patchConfigFile("config.json", [
  { op: "replace", path: ["server", "host"], value: "0.0.0.0" },
  { op: "add", path: ["server", "ssl"], value: true },
  { op: "remove", path: ["legacySection"] },
]);

setConfigValue​

ファイル内のネストした値を追加または置換します。1つの add 操作を patchConfigFile に渡します。

function setConfigValue(
  filePath: string,
  path: readonly (string | number)[],
  value: unknown,
  options?: PatchConfigOptions,
): Promise<void>;
await setConfigValue("config.yaml", ["database", "port"], 5432);

deleteConfigValue​

ファイル内の既存のネストした値を削除します。1つの remove 操作を patchConfigFile に渡します。

function deleteConfigValue(
  filePath: string,
  path: readonly (string | number)[],
  options?: PatchConfigOptions,
): Promise<void>;
await deleteConfigValue("config.json", ["features", "betaPreview"]);

withFileLock​

プロセス内キューと排他的ロックファイル（<file>.confedit.lock）を使って非同期コールバックを実行します。ロックは所有権トークンを使用します。allowStaleRecovery が true で、経過時間が staleThresholdMs を超えた場合のみ古いロックを回復します。PID は再利用される可能性があるため検査しません。

function withFileLock<T>(
  filePath: string,
  callback: () => Promise<T>,
  options?: FileLockOptions,
): Promise<T>;
パラメーター型説明
filePathstringロックするファイル。
callback() => Promise<T>ロック保持中に実行する処理。
optionsFileLockOptions下記を参照。

戻り値: callback の結果（Promise<T>）。コールバックが例外を送出しても、finally ブロックでロックを解放します。

FileLockOptions​

オプション型既定値説明
timeoutMsnumber10000ロックの最大待機時間（ミリ秒）。0 以上である必要があります。
retryDelayMsnumber25初回再試行待機時間（ミリ秒）。正の値が必要です。待機時間は1.5倍ずつ増え、最大1000ミリ秒です。
staleThresholdMsnumbermax(timeoutMs * 2, 60000)回復を許可するロック経過時間（ミリ秒）。正の値が必要です。
allowStaleRecoverybooleanfalse古いロックの自動回収。実行中のトランザクションを中断しないよう、Electron の単一メインプロセス向けに既定で無効です。
import { withFileLock } from "@powerduck/conf-patch";

await withFileLock("state.json", async () => {
  // ... read, modify, write ...
}, { timeoutMs: 5000 });

releaseAllLocalLocks​

現在のプロセスが所有するロックファイルをすべて削除します。実行中のファイルトランザクションが終わった後、アプリ終了時に使用してください。Electron の非同期クリーンアップでは最初の終了イベントを止め、処理後に終了を再開します。使用例を参照してください。個別ロックの削除エラーは無視します。

function releaseAllLocalLocks(): Promise<void>;

OpenAPI 検証​

validateOpenAPISpec​

JSON または YAML の OpenAPI/Swagger 内容を検証します。既定では入力を内容として扱い、inputKind: "file" の場合のみファイルパスと解釈します。検証は @powerduck/openapi-parser に委譲し、この関数が入力の安全対策を追加します。

function validateOpenAPISpec(
  input: string,
  options?: ValidateOpenApiOptions,
): Promise<AnyOpenAPIDocument>;
パラメーター型説明
inputstring仕様の元の内容。inputKind: "file" の場合はファイルパス。
optionsValidateOpenApiOptions下記を参照。

戻り値: 成功時の検証済み文書（Promise<AnyOpenAPIDocument>）。

例外: 空または文字列でない入力では TypeError。無効なオプションや検証中の失敗では OpenApiValidationError。

validateOpenAPIFile​

inputKind: "file" と、指定パスを設定した baseFilePath を使って validateOpenAPISpec を呼ぶ便利なラッパーです。allowedRootDirectory が必要です。

function validateOpenAPIFile(
  filePath: string,
  options?: ValidateOpenApiOptions,
): Promise<AnyOpenAPIDocument>;
import { validateOpenAPIFile } from "@powerduck/conf-patch";

const doc = await validateOpenAPIFile("./configs/openapi.yaml", {
  allowedRootDirectory: "./configs",
});

ValidateOpenApiOptions​

オプション型既定値説明
inputKind"content" | "file""content"input の解釈方法。
baseFilePathstring—参照解決コンテキストの基準パス。
allowedRootDirectorystring—ファイル入力のルートディレクトリ。inputKind が "file" の場合は必須。
timeoutMsnumber15000操作の制限時間（ミリ秒）。
maxInputBytesnumber5242880（5 MB）入力内容の最大バイト数。
maxDocumentNodesnumber100000解析後の文書の最大ノード数。DoS 対策。
maxDocumentDepthnumber100最大ネスト深度。DoS 対策。
maxValidationErrorsnumber50エラーメッセージに含める最大エラー数。
maxErrorMessageLengthnumber1000検証エラー1件あたりの最大文字数。
signalAbortSignal—任意のキャンセルシグナル。

OpenApiValidationError​

検証失敗時の構造化エラーです。クライアントに返す前にアプリケーション境界で適切なエラーに変換してください。メッセージや原因にローカルパスや文書の詳細が含まれることがあります。

class OpenApiValidationError extends Error {
  readonly code: string;
  readonly cause?: unknown;
  constructor(code: string, message: string, cause?: unknown);
}
プロパティ型説明
codestringプログラムで判別するエラーコード。下表を参照。
messagestring人が読める詳細説明。
causeunknown任意の元のエラー。

エラーコード​

コード意味
INVALID_OPTION無効なオプション値が指定されました。
INPUT_TOO_LARGE元の内容が maxInputBytes を超えています。
INPUT_FILE_TOO_LARGE入力ファイルがサイズ制限を超えています。
FILE_INPUT_FORBIDDENallowedRootDirectory なしでファイル入力を使用しました。
PATH_OUTSIDE_ROOT解決後のファイルパスが allowedRootDirectory の外部にあります。
PARSE_ERRORJSON/YAML 内容の解析に失敗しました。
INVALID_DOCUMENT_SHAPE文書が JSON オブジェクトではありません。
UNSUPPORTED_VERSION文書が対応する OpenAPI/Swagger バージョンを宣言していません。メジャーバージョン 2 と 3 のみ対応します。
DOCUMENT_TOO_DEEPネスト深度が maxDocumentDepth を超えています。
DOCUMENT_TOO_LARGEノード数が maxDocumentNodes を超えています。
SPEC_VALIDATION_FAILED仕様が OpenAPI 検証に失敗しました。
OPERATION_TIMEOUT操作が timeoutMs を超過しました。
OPERATION_ABORTEDsignal によって操作がキャンセルされました。
UNKNOWN_ERROR予期しないエラー。

ユーティリティ​

detectFormat​

ファイルパスまたは file:// URL の拡張子から ConfigFormat を判定します。

function detectFormat(filePath: string): ConfigFormat;
拡張子結果
.json"json"
.jsonc"jsonc"
.yaml, .yml"yaml"
その他の拡張子エラーを送出

normalizeFilePath​

ローカルパスまたは file: URL をネイティブの絶対パスに変換します。有効な空白と Unicode ファイル名を保持します。

function normalizeFilePath(filePath: string): string;

file: URL は fileURLToPath でデコードします。絶対パスはそのまま返し、相対パスは process.cwd() を基準に解決します。

アサーションヘルパー​

高度な利用や内部モジュール向けに再エクスポートされています。通常、アプリケーションから直接呼ぶ必要はありません。

assertNonEmptyString​

function assertNonEmptyString(value: unknown, label: string): asserts value is string;

value が空でない文字列でなければ TypeError を送出します。

assertPatchPath​

function assertPatchPath(
  path: readonly (string | number)[],
  label?: string, // default "path"
): void;

path が空でない配列で、各要素が空でない文字列または安全な0以上の整数という条件を満たさなければ例外を送出します。

assertPatchOperations​

function assertPatchOperations(ops: JsonPatchOp[]): void;

各操作を検証します。op は "add" | "replace" | "remove"、path は assertPatchPath を満たす必要があります。add/replace は自身の value プロパティを持つ必要があります。

assertConfigFormat​

function assertConfigFormat(format: ConfigFormat): void;

format が "json"、"jsonc"、"yaml" のいずれでもなければ例外を送出します。

getErrorMessage​

function getErrorMessage(error: unknown): string;

Error インスタンスでは error.message、それ以外では String(error) を返します。

createError​

function createError(message: string, cause: unknown): Error;

Error を作成し、Object.defineProperty で cause プロパティを追加します。古いランタイム向けの代替処理もあります。

型​

ConfigFormat​

type ConfigFormat = "json" | "jsonc" | "yaml";

JsonPathSegment​

type JsonPathSegment = string | number;

JsonPatchOp​

interface JsonPatchOp {
  op: "add" | "replace" | "remove";
  path: JsonPathSegment[];
  /** Required for "add" and "replace". */
  value?: unknown;
}
注意

対応するのは "add"、"replace"、"remove" のみです。"move"、"copy"、"test" は意図的に対象外としています。

PatchConfigOptions​

interface PatchConfigOptions {
  format?: ConfigFormat;
  strict?: boolean;
  lock?: boolean;
  lockTimeoutMs?: number;
  lockRetryDelayMs?: number;
  lockStaleThresholdMs?: number;
  /** Whether stale locks can be automatically reclaimed. Defaults to false. */
  allowStaleRecovery?: boolean;
}

FileLockOptions​

interface FileLockOptions {
  /** Max time to wait for a lock. Defaults to 10 seconds. */
  timeoutMs?: number;
  /** Initial retry delay. Defaults to 25ms. */
  retryDelayMs?: number;
  /** Explicit lock age after which recovery is allowed. */
  staleThresholdMs?: number;
  /** Whether stale locks can be automatically reclaimed. Defaults to false. */
  allowStaleRecovery?: boolean;
}

WriteConfigOptions​

interface WriteConfigOptions {
  lock?: boolean;
  lockTimeoutMs?: number;
  lockRetryDelayMs?: number;
  lockStaleThresholdMs?: number;
  allowStaleRecovery?: boolean;
}

PatchContentOptions​

interface PatchContentOptions {
  strict?: boolean;
}

OpenApiInputKind​

type OpenApiInputKind = "content" | "file";

AnyOpenAPIDocument​

検証が返す、対応 OpenAPI/Swagger 文書構造のユニオン型です。

type AnyOpenAPIDocument =
  | OpenAPIV2.Document      // Swagger 2.0
  | OpenAPIV3.Document      // OpenAPI 3.0.x
  | OpenAPIV3_1.Document     // OpenAPI 3.1.x
  | OpenAPIV3_2Document;    // OpenAPI 3.2 (permissive structural type)

OpenAPIV3_2Document は許容範囲の広い構造型です。

interface OpenAPIV3_2Document {
  openapi: string;
  info: Record<string, unknown>;
  paths?: Record<string, unknown>;
  [key: string]: unknown;
}
