設定

デスクトップクライアントの設定は、アプリの見た目とリクエストの発信方法をカバーします。アプリレベルの設定は API 文書への変更と分かれているため、テーマ切り替えやプロキシ構成が契約を変えることはありません。

外観​

  • テーマ——ライトとダークを切り替えます（theme.get、theme.set）。変更はアプリ全体に適用され永続化されます。
  • インターフェース言語——10 言語から選ぶか、システムに自動追従します。

リクエスト動作​

これらの設定は、リクエストワークスペースとシナリオから発信される外部リクエストを制御します。

  • リクエストタイムアウト（requestTimeoutMs）——ミリ秒。0 は無制限。
  • 厳格 SSL（strictSSL）——TLS 証明書を検証。自己署名や信頼されない証明書のサーバーでは無効にできます。
  • リダイレクト追従（followRedirects）と最大リダイレクト数（maxRedirects）。
  • HTTP バージョン（protocolVersion）——http1、http2、auto。
  • Cookie 無効化（disableCookies）——リクエストの Cookie 処理を切る。

プロキシ​

1 つのモード（off、system、custom）で外部プロキシを構成します。

  • off——プロキシを使わない。
  • system——OS のプロキシに追従。
  • custom——プロキシ URL を使い、任意でユーザー名、パスワード、バイパスリスト。

バイパスリストはホストとパターンを受け付けます（例: localhost,127.0.0.1、ワイルドカードホスト）。プロキシパスワードは書けますが読み戻されず、空値でクリアされます。

TLS とクライアント証明書​

カスタム信頼や双方向 TLS が必要な環境向けです。

  • カスタム CA——CA 証明書を有効化しパスを提供すると、内部または自己署名ルート証明書をリクエストが信頼します。
  • クライアント証明書（mTLS）——ホストごとに証明書を構成。証明書/キーペアか PFX、任意でパスフレーズ。ホストとポートでスコープを決めます。

証明書は追加、ID 指定で削除、またはクリアできます。証明書パスフレーズは書き込み専用で返されません。

統合ターミナル​

アプリには下部ターミナルパネルがあります。

  • terminal.open はパネルを表示します。{"cwd":"document"} を渡すと現在の文書のフォルダで開き、ホストが実際の絶対パスに解決します。
  • terminal.run は確認カードの後、明示的なシェルコマンドを入力して実行します。

コマンドはあなたが明示的に求めたときだけ実行され、パネル表示では何も実行されません。

ファイルとシェル操作​

  • shell.revealFile——現在の文書（または指定パス）をシステムファイルマネージャーで表示。
  • shell.openPath——規定アプリでファイルを開く。
  • shell.openExternal——システムブラウザで外部サードパーティページを開く。

Powerduck 公式ページは専用のリンクツール（app.officialLink）を使い、アプリを離れるのではなく会話内カードを描画します。

クライアントコード例​

任意の操作について、アシスタントはすぐ実行できるクライアントコードを生成し（clientcode.generate）、言語とクライアントライブラリの切り替え付きコードカードで提示します。C、C#、Go、Java、JavaScript、Node、Kotlin、PHP、Python、Ruby、Rust、shell、Swift などに対応。コードは会話に貼られずカードで提示されます。

アシスタント経由で設定を変える​

テーマや言語の切り替え、プロキシ設定、証明書エラーの無視、HTTP バージョン変更などのアプリレベル要求は、API 設計問題として扱われず設定ツールで処理されます。設定変更は適用前に確認を求めます。
