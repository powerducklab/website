デスクトップクライアント

デスクトップクライアントは、AI ネイティブのワークフローがあなた自身のマシン上で動く場所です。リポジトリから openapi.yaml を開き、望む結果を述べ、それをレビューします。仕様エディタ、HTTP クライアント、モックツール、ドキュメントジェネレーター、テストランナーを切り替える必要はなく、クラウドアカウントなしで始められます。

常にあなたがコントロールします。アシスタントが提案し、あなたが承認します。

ワークスペースでの 1 日​

以下はまさに、クライアントが中心に据えている瞬間です。

  • 仕様を開いて全体を把握する。 アシスタントが現在の文書を読み、できることをすぐに提案します——埋めるべきギャップ、完成させるドキュメント、テストすべきフロー。
  • API を構築する。 リソースを説明すると、アシスタントが操作を提案します。同じ操作を refine し続ける——パラメータを足す、レスポンスを締める、ステータスコードを調整する——と、文書全体にブレず、その API に留まります。
  • テストデータを準備する。 スキーマからリアルなサンプルデータを生成し、リクエストやシナリオに具体的な値を与えます。
  • 単一のリクエストか完全なシナリオを実行する。 1 回の呼び出しをデバッグするか、複数の操作をエンドツーエンドのフローに連結し、何が通って何が失敗したかの共有可能なレポートを得ます。
  • バックエンドの準備前に進める。 ローカルモックを起動し、実サービスの開発中も契約に沿って応答します。
  • API をコーディングエージェントに渡す。 仕様を MCP サーバーに変え、AI ツールが正しいパラメータで正しい操作を発見し呼べるようにします。
  • API の背後にあるデータベースを見通す。 仕様からテーブル、リレーション、SQL を導き、実データベースと突き合わせ、起きようとしている変更を把握します。
  • 会話を離れずに設定を変える。 テーマや言語の切り替え、プロキシの設定、環境変数の管理を、口頭で依頼するだけで行えます。

各モードとその用途​

1 つの文書がすべてのモードを駆動し、コンパクトなスイッチャーで行き来します。

モードできること
仕様メインモード: AI チャット、文書、ライブプレビュー
リクエストワークスペース実際の HTTP リクエストを送って検査。タブと環境に対応
シナリオテスト操作をフローに連結し、実行してレポートを得る
ドキュメント仕様をレンダリングされた API ドキュメントとして読む
MCP仕様から導いた MCP サーバーを確認して使う
モックサーバーAPI 開発中にローカルモックを実行する
データモデルテーブルとリレーションを導き、データベースと突き合わせ、SQL を生成する
設定テーマ、言語、プロキシ、証明書、ワークスペース設定

アシスタントとの協働方法​

自然言語で意図を説明すると、アシスタントが適切な能力を選び、確定的なエンジンがそれを検証し、あなたがカードで承認します。モデルが独断で文書を編集することはありません。

  • 仕様への変更は、きめ細かい操作を含むパッチカードとして届きます。既存の操作を編集するときは、依頼されたフィールドだけが変わります。
  • 読み取り専用の操作——操作の一覧、スキーマの取得、クエリの実行——は、アシスタントが回答の根拠とする事実を返します。
  • 書き込み操作は実行前に確認を求めます。

モデルはあなたが設定します。アプリを任意の OpenAI 互換プロバイダーに向け、設定で選べます。AI とモデルをご覧ください。

ローカルファーストがあなたに意味すること​

  • あなたの実際のファイル。 ディスク上の実ファイルを開き、編集し、保存し、ローカルの変更を追跡します。
  • CORS の壁がない。 リクエストは WebView ではなくローカルプロセス経由で送られるため、クロスオリジン制限が呼び出しを妨げません。
  • プロンプトとキーが非公開。 ローカルで処理され、ブラウザのネットワークパネルに現れません。
  • オフラインで動作。 設計、モック、ドキュメントはネットワーク不要。実リクエスト、Git 同期、ホスト型モデルだけがネットワークを必要とします。
  • ローカルの実行環境。 モック、シナリオランナー、データベースアクセス、ターミナルがあなたのマシン上で動きます。

デスクトップライセンス​

デスクトップクライアントは買い切りの永久ライセンスとして販売されています。一度買えば永久に所有でき、完全にオフラインで動作し、アカウントは不要です。ライセンスキーは購入時に生成され、一度だけ表示されます。月額サブスクリプションのホスティングサービス Powerduck Cloud とは別物です。Cloud の請求をご覧ください。
