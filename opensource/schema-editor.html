Schema-Aware Monaco Editor

A Monaco editor driven by any JSON Schema. Get ghost text completion, enum dropdowns, example auto-fill, property validation, and real-time diagnostics — for JSON, YAML, and JavaScript documents.

Quick Start

Embed in React in minutes

import { useState } from "react";
import { SchemaEditor } from "@powerduck/schema-editor/react";

function MyEditor() {
  const [value, setValue] = useState('{"name": ""}');
  return (
    <SchemaEditor
      value={value}
      onChange={setValue}
      language="json"
      schema={{
        type: "object",
        properties: { name: { type: "string" } },
      }}
      theme="dark"
    />
  );
}
// With enum, the editor shows a dropdown when editing "status"
const schema = {
  type: "object",
  required: ["name", "status"],
  properties: {
    name: { type: "string", description: "Pet name" },
    status: {
      type: "string",
      enum: ["available", "pending", "sold"],
    },
  },
};
// Switch to YAML — same schema, same completion

Features

Your JSON Schema, your editor

The editor reads your schema and turns it into a guided editing experience.

01

Ghost Text Completion

Inline gray text suggests the next property or value as you type. Based on JSON Schema properties, required fields, and enum values. Press Tab to accept.

02

Popup Completion

Intellisense-style dropdowns show available properties, enum values, and snippets. Filtered by current scope and existing keys to avoid duplicates.

03

Real-time Diagnostics

Type errors, missing required fields, and invalid enum values are underlined as you type. A status bar shows the current diagnostic count.

04

JSON, YAML & JavaScript

Three languages share the same completion engine. JSON for config files, YAML for OpenAPI docs, and JavaScript for schema authoring with snippets.

05

$ref Resolution

Schema references are resolved automatically. resolveReference() handles local pointers, remote schemas, and circular reference detection.

06

Sample Generation

generateSample() creates a valid example document from a JSON Schema. Include required fields, enums, and default values.
