Generate HTTP client code from any OpenAPI doc.

Drop-in code generation for 21 languages and 41 language/client combinations. Browser-compatible, zero runtime dependencies, with a plugin system for custom generators.

Quick Start

Generate code in three lines

import { generate } from "@powerduck/openapi-codegen";

const document = {
  openapi: "3.1.0",
  info: { title: "Demo API", version: "1.0.0" },
  servers: [{ url: "https://api.example.com/v1" }],
  paths: {
    "/users/{id}": {
      get: {
        operationId: "getUser",
        parameters: [{ name: "id", in: "path", required: true, schema: { type: "string" } }],
        responses: { "200": { description: "OK" } },
      },
    },
  },
};

// Full GenerateOptions — all fields shown
const code = generate({
  document,                          // OpenAPI document (required if no request)
  path: "/users/{id}",             // Operation path
  method: "get",                  // HTTP method
  language: "python",              // Target language (required)
  client: "requests",              // HTTP client (required)
  serverUrl: "https://api.example.com/v1", // Override servers[0].url
  securityValues: { bearerAuth: "my-token" }, // Auth values
  softRefMode: false,              // Soft $ref resolution
});

console.log(code);
import { register, generate } from "@powerduck/openapi-codegen";

// Register a custom generator — full RequestIR API shown
register({
  language: "mylang",
  client: "myclient",
  generate(request) {
    // RequestIR fields:
    const { method, baseUrl, path, parameters, headers, body, security } = request;
    // parameters: Parameter[] — { name, in: "path"|"query"|"header"|"cookie", value, style?, explode?, allowReserved? }
    // headers: Parameter[] — same shape as parameters
    // body?: Body — { mediaType, value, encoding? }
    // security: Security[] — { name, type, scheme?, in?, paramName?, value }
    return `// ${method.toUpperCase()} ${baseUrl}${path}`;
  },
});

// Or pass a pre-built RequestIR directly (no document needed)
const code = generate({
  language: "mylang",
  client: "myclient",
  request: {
    method: "post",
    baseUrl: "https://api.example.com",
    path: "/users",
    parameters: [{ name: "verbose", in: "query", value: true }],
    headers: [{ name: "X-Request-Id", in: "header", value: "abc-123" }],
    body: { mediaType: "application/json", value: { name: "John" } },
    security: [{ name: "bearerAuth", type: "http", scheme: "bearer", value: "token" }],
  },
});
import { use } from "@powerduck/openapi-codegen";

const myPlugin = {
  name: "my-custom-plugin",
  register({ register }) {
    register({
      language: "pluginlang",
      client: "pluginclient",
      generate(req) { return `// ${req.method}`; },
    });
  },
};

use(myPlugin);
import { list, get } from "@powerduck/openapi-codegen";

const all = list();
console.log(`Available: ${all.length} generators`);
all.forEach(({ language, client }) => console.log(`${language}/${client}`));

const gen = get("javascript", "fetch");
Features

Everything you need for code generation

Built for API documentation, SDK scaffolding, and developer tooling.

01

21 Languages, 41 Clients

TypeScript fetch/axios/node, Python requests/httpx/aiohttp, Go net/http/fasthttp, Java OkHttp/Unirest, Ruby, PHP, cURL, wget, and more.

02

Browser Compatible

Pure TypeScript with no Node.js dependencies. Runs in browsers, Edge Functions, Web Workers, and any modern JS runtime.

03

Zero Runtime Dependencies

No heavy dependencies shipped to your users. The entire generator compiles to a small, tree-shakeable ESM/CJS bundle.

04

Plugin System

Register custom generators with register() or use(plugin). Extend or override any built-in language without forking.

05

Accurate $ref Resolution

Properly resolves OpenAPI $ref pointers for request bodies, parameters, and schemas. Handles circular references safely.

06

Security Value Injection

Pass securityValues to inject API keys, bearer tokens, and basic auth credentials directly into generated code.

functiongenerate(options)Generate an HTTP request example for an OpenAPI operation
Parameter Type Description
options.document object OpenAPI document object (required when no request)
options.path string Operation path, e.g. "/users/{id}" (required with document)
options.method string HTTP method lowercase: get, post, put, delete, patch (required with document)
options.languagerequired string Target language, e.g. "python"
options.clientrequired string HTTP client, e.g. "requests"
options.request RequestIR Pre-normalized request (skips document lookup)
options.serverUrl string Override server base URL
options.securityValues object Map of security scheme names to values
options.softRefMode boolean Graceful $ref resolution mode
