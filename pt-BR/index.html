Perguntas frequentes

As primeiras dúvidas dos desenvolvedores

A revisão de código é exclusiva para projetos de API?

Não. Abra um projeto local para revisar alterações Git e código relacionado. O desenvolvimento de APIs tem um espaço de trabalho independente.

Quais versões do OpenAPI são compatíveis?

OpenAPI 3.0, 3.1 e 3.2. O Powerduck identifica a versão declarada e valida o dialeto correspondente, sem limitar todas as versões a um subconjunto comum.

Como o servidor MCP é gerado?

Operações com operationId se tornam ferramentas MCP. Os argumentos são derivados dos parâmetros e dos esquemas de requestBody. Esquemas de componentes podem ser expostos como recursos. O servidor gerado é atualizado sempre que a especificação muda.

Planos e tarefas?

Comece com Free. Os planos pagos aumentam as conversas com IA e revisões de código; o modelo integrado está incluído.
