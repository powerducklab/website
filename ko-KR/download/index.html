칩 종류를 모르시겠나요?

Apple 메뉴 → 이 Mac에 관하여를 여세요. ‘칩: Apple M…’이면 Apple Silicon, ‘프로세서: Intel…’이면 Intel입니다.

.dmg 파일을 열고 Powerduck을 응용 프로그램 폴더로 드래그하세요.

시작하기 전에

로그인해야 하나요?

Cloud 계정 없이 데스크톱 앱에서 로컬 작업을 시작할 수 있습니다. Cloud 호스팅, 구매, 호스팅 AI 크레딧이 필요할 때 로그인하세요.

무엇을 다운로드하며, 어떤 항목이 유료인가요?

로컬 사용에는 Cloud 구매가 필요하지 않습니다. 무료로 명세 두 개를 사용할 수 있으며, 승인된 공유 보상으로 한도를 늘릴 수 있습니다. 데스크톱 라이선스를 구매하면 명세 개수 제한이 사라집니다. 본인 모델 키의 사용료는 해당 공급자가 청구합니다. 호스팅 모델 크레딧과 Cloud 호스팅 요금은 별도입니다.

제품과 요금제 비교 →
파일과 AI 요청은 어디로 전송되나요?

로컬 파일 사용에는 계정이 필요하지 않습니다. 원격 AI를 사용하면 관련 컨텍스트가 설정한 공급자에게 전송됩니다. Cloud에 게시할 때는 선택한 콘텐츠가 업로드됩니다. 선택적 사용 통계는 기본적으로 꺼져 있습니다. 수집 항목과 설정 방법은 개인정보 처리방침을 확인하세요.
