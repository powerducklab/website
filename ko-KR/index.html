개발자가 먼저 궁금해하는 것들

코드 검토는 API 프로젝트 전용인가요?

아닙니다. 로컬 코드 프로젝트를 열어 Git 변경 사항과 관련 코드를 검토할 수 있습니다. API 개발은 독립된 작업 공간입니다.

어떤 OpenAPI 버전을 지원하나요?

OpenAPI 3.0, 3.1, 3.2를 지원합니다. 공통 기능만으로 검증하지 않고 파일에 선언된 버전을 감지해 해당 규격으로 검증합니다.

MCP 서버는 어떻게 생성되나요?

operationId가 있는 작업이 MCP 도구가 됩니다. 매개변수와 requestBody 스키마에서 인수를 생성합니다. 컴포넌트 스키마를 리소스로 제공할 수도 있습니다. 명세가 변경될 때마다 생성된 서버가 갱신됩니다.

요금제와 작업 횟수?

Free로 시작하세요. 유료 요금제는 AI 대화와 코드 리뷰 횟수를 늘려 주며 내장 모델이 포함됩니다.
