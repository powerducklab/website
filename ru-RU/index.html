Вопросы и ответы

Что разработчики спрашивают в первую очередь

Ревью кода подходит только для API-проектов?

Нет. Откройте локальный проект для проверки изменений Git и связанного кода. Разработка API — отдельное рабочее пространство.

Какие версии OpenAPI поддерживаются?

OpenAPI 3.0, 3.1 и 3.2. Powerduck определяет объявленную версию и проверяет документ по соответствующему диалекту, а не по общему минимальному набору правил.

Как создаётся MCP-сервер?

Операции с operationId становятся MCP-инструментами. Аргументы формируются из параметров и схем requestBody. Схемы компонентов можно предоставлять как ресурсы. Сгенерированный сервер обновляется при изменении спецификации.

Тарифы и задачи?

Начните с Free. Платные планы увеличивают число диалогов с ИИ и проверок кода; встроенная модель включена.
