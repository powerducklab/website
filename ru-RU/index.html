Редактор спецификаций OpenAPI

Редактор спецификаций OpenAPI

Структура документа строится по реальной спецификации, а не угадывается по отступам. Перемещайтесь по дереву путей и компонентов и исправляйте ошибки прямо на месте.

  • Проверка с учётом схемы. Валидация по диалекту 3.0, 3.1 или 3.2, который объявлен в вашем файле.
  • Навигация по ссылкам $ref. Переходите к определениям, смотрите места использования и получайте подсказки при опечатках в ссылках.
  • Редактирование исходного файла. Ваш репозиторий остаётся источником истины.
  • Диагностика с названиями правил. Ошибки CI и сообщения редактора используют одни и те же термины.

Отладка API

Отладка API по вашей спецификации

Привычный разработчикам конструктор запросов с дополнительной возможностью: проверкой ответов по контракту.

  • Коллекции из путей и тегов. Без импорта и ручной повторной синхронизации.
  • Проверка контракта для каждого ответа. Замечайте необъявленные свойства, отсутствующие поля и несовпадения типов прямо в ответе.
  • Окружения и переменные. Используйте существующие настройки разработки и тестовых окружений.
  • Аутентификация из securitySchemes. Настройки Bearer, API-ключей и OAuth берутся из спецификации.

Генератор MCP-серверов

Создайте MCP-сервер из OpenAPI

В вашей спецификации уже есть описание инструментов. Powerduck превращает её в работающий MCP-сервер и показывает, какие поля OpenAPI послужили источником для каждого инструмента.

  • Понятное происхождение. Каждый инструмент связан с исходной операцией, operationId и схемой.
  • Видимые ограничения и пропуски. Недостающие метаданные явно отмечаются, а не приводят к незаметному созданию неполноценных инструментов.
  • Обновление при сохранении. Меняйте спецификацию — инструменты обновятся без отдельной сборки.
  • Локальные транспорты. Используйте stdio или HTTP для локальных агентов и рабочих процессов.

Локальная работа, удалённые сервисы и ваш выбор

Для локальных файлов аккаунт не нужен. При работе с удалённым ИИ соответствующий контекст отправляется настроенному провайдеру. При публикации в Cloud загружается выбранное вами содержимое. Вопросы и ответы

Что разработчики спрашивают в первую очередь

Практические подробности о локальных файлах, версиях OpenAPI, генерации MCP и лицензировании.

Загружает ли Powerduck мою спецификацию OpenAPI куда-либо?

Для локальных файлов аккаунт не нужен. При работе с удалённым ИИ соответствующий контекст отправляется настроенному провайдеру. При публикации в Cloud загружается выбранное вами содержимое. Необязательная статистика использования по умолчанию отключена; состав данных и настройки описаны в политике конфиденциальности.

Какие версии OpenAPI поддерживаются?

OpenAPI 3.0, 3.1 и 3.2. Powerduck определяет объявленную версию и проверяет документ по соответствующему диалекту, а не по общему минимальному набору правил.

Как создаётся MCP-сервер?

Операции с operationId становятся MCP-инструментами. Аргументы формируются из параметров и схем requestBody. Схемы компонентов можно предоставлять как ресурсы. Сгенерированный сервер обновляется при изменении спецификации.

Настольная лицензия — это подписка?

Нет. Powerduck Desktop — бессрочная лицензия с разовой оплатой. Обновления в пределах основной версии включены. Переход на будущие основные версии остаётся добровольным.

Можно ли продолжать использовать коллекции Postman?

Да. Существующие коллекции и окружения можно использовать и дальше. Powerduck считает спецификацию OpenAPI основным контрактом и помогает находить отклонения запросов от него.

Работает ли это в CI?

Да. Тот же движок валидации и генерации доступен через @powerduck/openapi-cli — инструмент командной строки для проверок в пул-реквестах и автоматических конвейерах. Он поддерживает пакетное тестирование шести протоколов (HTTP, SSE, WebSocket, gRPC, MCP, GraphQL), настройку параллелизма и отчёты, совместимые с JUnit, для интеграции с CI.
