Windows 版 Powerduck 測試版

適用於 Windows 10/11 的未簽章測試版。一般新款電腦請選 64 位元（x64），舊款系統請選 32 位元（x86）。完成程式碼簽章前，SmartScreen 可能顯示首次執行警告。

首次執行時 Windows 可能彈出安全警告

這個測試版尚未完成程式碼簽章，首次執行可能出現安全性提示。若 SmartScreen 顯示「Windows 已保護您的電腦」，可選擇「其他資訊」→「仍要執行」。若 Edge 或 Chrome 封鎖下載，可選擇「保留」→「仍要保留」。

安裝之後

一份檔案，開啟完整 API 工作流。

  1. 01

    開啟你的規格

    開啟已有的 OpenAPI YAML 或 JSON 檔案，也可以新建 API。本機檔案始終是唯一事實來源。

    瞭解編輯器 →
  2. 02

    傳送第一個請求

    選擇端點，設定環境與驗證方式，再於「偵錯與測試」中送出請求並查看回應。

    查看偵錯指南 →
  3. 03

    讓 AI 參與工作流

    設定自己的模型服務供應商，或使用託管 AI 額度，透過對話設計和完善 API。

    設定 AI 模型 →

開始前，你可能想瞭解

需要登入嗎？

桌面應用中的本機工作無需 Cloud 帳號。需要 Cloud 託管、購買產品或使用託管 AI 額度時，再登入帳號。

下載的是哪個產品？哪些功能需要付費？

本機功能不需要購買 Cloud。免費方案可使用兩份規格；分享獎勵經審核通過後可增加名額。桌面授權可解除名額限制。使用自備 API 金鑰時，模型費用由服務供應商收取；託管模型額度與 Cloud 託管另行計費。

對比產品與價格 →
檔案和 AI 請求會傳送到哪裡？

本機檔案讀寫不需要帳號。遠端 AI 會將相關內容傳送至你設定的模型服務；主動發布至 Cloud 時才會上傳所選內容。選用的使用統計預設關閉，收集欄位與控制方式請參閱隱私權政策。
