常見問題

開發者最先問的問題

程式碼審閱只能用於 API 專案嗎？

不是。開啟本機程式碼專案，即可檢查 Git 變更與關聯程式碼。API 開發是獨立工作台，不必先使用程式碼審閱。

支援哪些 OpenAPI 版本？

支援 OpenAPI 3.0、3.1 和 3.2。Powerduck 會偵測宣告的版本，依照對應方言驗證，而非將所有版本限制在共通功能範圍內。

MCP 伺服器是怎麼生成的？

帶有 operationId 的操作會轉成 MCP 工具，參數則由 parameters 與 requestBody 的結構描述推導而來。元件的結構描述可公開為資源。規格變更時，產生的伺服器也會更新。

方案與任務次數?

從 Free 開始。付費方案增加 AI 對話與程式碼審查次數，內建模型已包含在內。
