常见问题

开发者最先问的问题

关于本地文件、OpenAPI 版本、MCP 生成与授权的实用细节。

Powerduck 会把我的 OpenAPI 规范上传到任何地方吗？

本地文件读写无需账号。远程 AI 会向你配置的模型服务发送相关上下文；主动发布到 Cloud 时上传所选内容。可选使用统计默认关闭，采集字段与开关见隐私说明。

支持哪些 OpenAPI 版本？

OpenAPI 3.0、3.1 和 3.2。Powerduck 会检测声明的版本，并按对应的方言校验，而不是采用最小公约数。

MCP 服务器是怎么生成的？

带 operationId 的 operation 会成为 MCP 工具，参数由 parameters 和 requestBody schema 推导而来。组件 schema 可作为资源暴露。规范一旦变化，生成的服务器就会更新。

桌面授权是订阅制吗？

不是。Powerduck 桌面版是一次性购买的永久授权，大版本内的更新都包含在内，未来的大版本升级仍然可选。

我还能继续用 Postman 集合吗？

可以。已有的集合和环境都能继续使用。Powerduck 把 OpenAPI 规范当作权威契约，并帮你找出请求与契约的偏差。

能用在 CI 里吗？

可以。同一套校验和生成引擎通过 @powerduck/openapi-cli 暴露，这是一个可用于 CI 的命令行工具，在 Pull Request 和自动化流水线中运行。它支持跨 6 种协议（HTTP、SSE、WebSocket、gRPC、MCP、GraphQL）批量测试、可配置并发，并生成兼容 JUnit 的报告用于 CI 集成。
