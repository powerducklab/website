开始前，你可能想了解

需要登录吗？

桌面应用中的本地工作无需 Cloud 账号。需要 Cloud 托管、购买产品或使用托管 AI 额度时，再登录账号。

下载的是哪个产品？哪些功能需要付费？

本地功能不需要购买 Cloud。免费使用包含两个规范名额，审核通过的分享奖励可增加名额；桌面授权解除名额限制。自带 Key 的费用由模型服务商收取，托管模型额度与 Cloud 托管另行计费。

对比产品与价格 →
文件和 AI 请求会发送到哪里？

本地文件读写无需账号。远程 AI 会向你配置的模型服务发送相关上下文；主动发布到 Cloud 时上传所选内容。可选使用统计默认关闭，采集字段与开关见隐私说明。
