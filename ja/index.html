よくある質問

開発者が最初に尋ねる質問

コードレビューはAPIプロジェクト専用ですか？

いいえ。ローカルのコードプロジェクトを開き、Gitの変更や関連コードを確認できます。API開発は独立したワークスペースです。

どの OpenAPI バージョンをサポートしていますか？

OpenAPI 3.0、3.1、3.2。Powerduck は宣言されたバージョンを検出し、最小公倍数ではなく該当する方言で検証します。

MCP サーバーはどのように生成されますか？

operationId を持つ operation が MCP ツールになります。引数は parameters と requestBody スキーマから導出されます。コンポーネントスキーマはリソースとして公開できます。仕様が変更されるたびに、生成サーバーが更新されます。

プランとタスク回数?

まずは Free から。有料プランは AI 会話とコードレビューの回数が増え、内蔵モデルも含まれます。
