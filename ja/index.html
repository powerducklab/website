OpenAPI スペックエディタ

OpenAPI スペックエディタ

アウトラインは、インデントによる推測ではなく、仕様の実際の構造に従います。パスとコンポーネントをツリーで移動し、問題のある場所で修正できます。

  • スキーマ対応の検証。 ファイルが実際に宣言する 3.0、3.1、3.2 の方言に対して検証します。
  • 解決済み $ref ナビゲーション。 定義へジャンプし、使用箇所を確認し、スペルミスのある参照の候補を表示します。
  • その場で編集。 リポジトリが唯一の信頼できる情報源であり続けます。
  • ルール名付きの問題表示。 CI の失敗とエディタの診断が同じ用語で表示されます。

API デバッグ

仕様に基づく API デバッグ

開発者が使い慣れたツールと同じ形状のリクエストビルダーに加え、それらのツールが既定ではできないこと、つまり契約に対するレスポンス検証を提供します。

  • パスとタグから生成されるコレクション。 インポートの手順も、手動での再同期も不要です。
  • すべてのレスポンスで契約チェック。 宣言外プロパティ、欠落フィールド、型のずれをインラインで検出。
  • 環境と変数。 既存の開発・ステージング設定を再利用。
  • securitySchemes から始まる認証。 Bearer、API キー、OAuth の設定が仕様から始まります。

MCP サーバージェネレータ

OpenAPI から MCP サーバーを生成

あなたの仕様は、すでにツールマニフェストです。Powerduck はそれを実行可能な MCP サーバーにコンパイルし、各ツールがどの OpenAPI フィールドから生まれたかを正確に表示します。

  • 見える来歴。 すべてのツールは、その operation、operationId、スキーマまで追跡できます。
  • 劣化およびスキップ状態。 メタデータの欠落は、弱いツールを黙って作るのではなく、可視化されます。
  • 保存のたびに再生成。 仕様を変更すると、ビルドステップなしでツールが更新されます。
  • ローカルトランスポート。 ローカルエージェントとワークフローのために stdio または HTTP で実行。

API ドキュメントジェネレータ

同じ契約から生まれる API ドキュメント

リファレンスドキュメントは OpenAPI モデルから直接生成され、静的ファイルとして書き出され、好きな場所でホストできます。

  • スキーマから作られるパラメータ表。 必須フラグ、列挙、説明が同期し続けます。
  • 複数言語のサンプル。 operation から cURL、Node、Python、Go の例を生成。
  • 実際の契約に基づくレスポンス。 成功・エラーレスポンスは、デバッガが検証するのと同じオブジェクトから取得されます。
  • 静的書き出し。 実行時の依存も、ドキュメントプラットフォームへのロックインもありません。

ローカル作業とリモートサービスの境界

ローカルファイルの読み書きにアカウントは不要です。リモート AI には設定したプロバイダーへ関連コンテキストを送信します。Cloud への公開時は選択した内容をアップロードします。任意の利用統計は初期設定でオフです。項目と設定はプライバシー説明をご覧ください。

プライバシーポリシー

ローカル機能に Cloud の購入は不要です。無料利用は仕様ファイル 2 件まで。審査済みの共有特典で枠を追加でき、デスクトップライセンスで枠の制限を解除できます。持ち込みキーの料金はモデル提供者が請求し、ホスト型モデルのクレジットと Cloud は別料金です。

Powerduck は私の OpenAPI 仕様をどこかにアップロードしますか？

ローカルファイルの読み書きにアカウントは不要です。リモート AI には設定したプロバイダーへ関連コンテキストを送信します。Cloud への公開時は選択した内容をアップロードします。任意の利用統計は初期設定でオフです。項目と設定はプライバシー説明をご覧ください。

どの OpenAPI バージョンをサポートしていますか？

OpenAPI 3.0、3.1、3.2。Powerduck は宣言されたバージョンを検出し、最小公倍数ではなく該当する方言で検証します。

MCP サーバーはどのように生成されますか？

operationId を持つ operation が MCP ツールになります。引数は parameters と requestBody スキーマから導出されます。コンポーネントスキーマはリソースとして公開できます。仕様が変更されるたびに、生成サーバーが更新されます。

デスクトップライセンスはサブスクリプションですか？

いいえ。Powerduck Desktop は一度購入する永久ライセンスで、メジャーバージョン内の更新が含まれます。将来のメジャーアップグレードは任意です。

Postman コレクションを使い続けられますか？

はい。既存のコレクションと環境は引き続き使用できます。Powerduck は OpenAPI 仕様を権威ある契約として扱い、リクエストがどこで契約から外れるかを特定するのに役立ちます。

CI で使えますか？

はい。同じ検証・生成エンジンは @powerduck/openapi-cliを通じて公開されています。これは CI 対応のコマンドラインツールで、プルリクエストや自動パイプラインで実行されます。6 つのプロトコル（HTTP、SSE、WebSocket、gRPC、MCP、GraphQL）にわたる一括テスト、設定可能な並行処理、CI 統合向けの JUnit 互換レポートをサポートします。
