محرر مواصفات OpenAPI

يتبع المخطط البنية الفعلية للمواصفة بدلاً من تخمينها من المسافات البادئة. تصفّح المسارات والمكونات كشجرة، وأصلح الأخطاء في مواضعها.

  • تحقق يراعي المخطط. تحقق وفق صيغة 3.0 أو 3.1 أو 3.2 التي يعلنها ملفك فعليًا.

  • تشخيص مع أسماء القواعد. تستخدم أخطاء التكامل المستمر وتشخيصات المحرر المصطلحات نفسها.

تصحيح أخطاء API

تصحيح أخطاء API وفق مواصفتك

منشئ طلبات مألوف للمطورين، مع إمكانية إضافية: التحقق من الاستجابات وفق العقد.

  • مجموعات من المسارات والوسوم. دون استيراد أو إعادة مزامنة يدوية.
  • فحص العقد لكل استجابة. اكتشف الخصائص غير المعلنة والحقول المفقودة واختلاف الأنواع داخل الاستجابة مباشرةً.
  • البيئات والمتغيرات. أعد استخدام إعدادات التطوير وبيئة ما قبل الإنتاج الحالية.
  • المصادقة من securitySchemes. تبدأ إعدادات Bearer ومفتاح API وOAuth من المواصفة.

منشئ خوادم MCP

أنشئ خادم MCP من OpenAPI

تحتوي مواصفتك بالفعل على تعريفات الأدوات. يحوّلها Powerduck إلى خادم MCP قابل للتشغيل ويبيّن حقول OpenAPI التي نتجت عنها كل أداة.

  • مصدر واضح. يمكن تتبّع كل أداة إلى العملية وoperationId والمخطط الأصلي.
  • إظهار القيود والعناصر المتجاوزة. تظهر البيانات الوصفية الناقصة بدلاً من إنشاء أدوات غير مكتملة بصمت.
  • إعادة الإنشاء عند الحفظ. غيّر المواصفة فتتحدث الأدوات دون خطوة بناء منفصلة.
  • وسائل نقل محلية. شغّل عبر stdio أو HTTP للوكلاء ومسارات العمل المحلية.

منشئ توثيق API

توثيق API من العقد نفسه

أنشئ توثيقًا مرجعيًا مباشرةً من نموذج OpenAPI، وصدّره كملفات ثابتة واستضفه حيث تريد.

  • جداول المعلمات من المخططات. تبقى الحقول الإلزامية والقيم المعدّدة والأوصاف متزامنة.
  • أمثلة بلغات متعددة. أنشئ أمثلة cURL وNode وPython وGo من العمليات.
  • استجابات من العقد الفعلي. تأتي استجابات النجاح والأخطاء من الكائنات نفسها التي يتحقق منها مصحح الأخطاء.
  • تصدير ثابت. دون اعتماديات وقت تشغيل أو ارتباط بمنصة توثيق بعينها.

مساحة عمل محلية مدعومة بالذكاء الاصطناعي تتمحور حول ملف OpenAPI نفسه.

دون حاجة إلى السحابةلا تحتاج إلى رفع المواصفة للعمل محليًا.
دون مزامنة يدويةلا توجد مواد منفصلة تحتاج إلى مزامنتها مع العقد.
دون نسخة إضافيةملف YAML أو JSON الحالي هو مساحة عملك.

العمل المحلي والخدمات البعيدة وخياراتك

لا تحتاج الملفات المحلية إلى حساب. يرسل الذكاء الاصطناعي البعيد السياق ذي الصلة إلى المزود الذي أعددته، ويرفع النشر في Cloud المحتوى الذي تختاره. إحصاءات الاستخدام الاختيارية معطلة افتراضيًا؛ راجع سياسة الخصوصية لمعرفة البيانات وعناصر التحكم.

الأسئلة الشائعة

ما يسأل عنه المطورون أولاً

تفاصيل عملية عن الملفات المحلية وإصدارات OpenAPI وإنشاء MCP والترخيص.

هل يرفع Powerduck مواصفة OpenAPI الخاصة بي إلى أي مكان؟

لا تحتاج الملفات المحلية إلى حساب. يرسل الذكاء الاصطناعي البعيد السياق ذي الصلة إلى المزود الذي أعددته، ويرفع النشر في Cloud المحتوى الذي تختاره. إحصاءات الاستخدام الاختيارية معطلة افتراضيًا؛ راجع سياسة الخصوصية لمعرفة البيانات وعناصر التحكم.

ما إصدارات OpenAPI المدعومة؟

OpenAPI 3.0 و3.1 و3.2. يكتشف Powerduck الإصدار المعلن ويتحقق وفق صيغته المناسبة، بدلاً من الاكتفاء بالحد الأدنى المشترك.

كيف يُنشأ خادم MCP؟

تصبح العمليات التي تحتوي على operationId أدوات MCP. تُشتق الوسيطات من المعلمات ومخططات requestBody. ويمكن إتاحة مخططات المكونات كموارد. يتحدث الخادم المُنشأ كلما تغيرت المواصفة.

هل ترخيص سطح المكتب اشتراك؟

لا. Powerduck Desktop ترخيص دائم يُشترى مرة واحدة، ويتضمن التحديثات ضمن الإصدار الرئيسي نفسه. تبقى الترقية إلى الإصدارات الرئيسية اللاحقة اختيارية.

هل يمكنني الاستمرار في استخدام مجموعات Postman؟

نعم. يمكنك مواصلة استخدام المجموعات والبيئات الحالية. يعتمد Powerduck مواصفة OpenAPI كعقد مرجعي ويساعدك على تحديد مواضع اختلاف الطلبات عنه.

هل يعمل في التكامل المستمر؟

نعم. يتوفر محرك التحقق والتوليد نفسه عبر @powerduck/openapi-cli، وهي أداة سطر أوامر جاهزة للتكامل المستمر تعمل في طلبات السحب ومسارات التشغيل الآلية. تدعم الاختبار الجماعي عبر 6 بروتوكولات (HTTP وSSE وWebSocket وgRPC وMCP وGraphQL)، وضبط التزامن، وتقارير متوافقة مع JUnit للتكامل مع CI.
