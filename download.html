Before you get started

Do I need to sign in?

You can start local work in the desktop app without a Cloud account. Sign in when you need Cloud hosting, purchases or hosted AI credits.

What am I downloading, and what is paid?

This page downloads the desktop app. Its perpetual license, optional Cloud hosting and hosted AI credits are separate products. Choose only what your workflow needs.

Compare products and pricing →
Where do my files and AI requests go?

Your spec is a local file. API debugging sends requests to the endpoints you configure. AI features send relevant context to the model provider you choose; Cloud publishing is a separate action.
